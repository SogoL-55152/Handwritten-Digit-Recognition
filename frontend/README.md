# frontend — Vue 3 网页端（基础体验版 / W2 开发模式）

Vue 3 + Vite + Pinia + Vue Router。默认 `development` 保留 W2 路线；`pilot` 提供仅画板、账号、帮助和隐私的基础体验。平台运营权限仍由服务端确认，不能通过缓存或界面模式获得。当前不使用 Element Plus/ECharts，不生成虚构训练曲线。

## 当前基础体验版（pilot）

接口与规则以 [Pilot 接口与配置约定](../docs/Pilot-接口与配置约定.md) 为准。

1. 在本目录将 `.env.example` 复制为 `.env.local`，设置 `VITE_APP_MODE=pilot`。不设置时默认 `development`，与 Vite 自身的 `--mode` / NODE_ENV 不是同一个开关。
2. 填写公开字段 `VITE_PILOT_OPERATOR`（真实维护 / 运营主体）、`VITE_PILOT_CONTACT`（真实人工联系方式）、`VITE_PILOT_PRIVACY_VERSION`（说明版本）。这些字段会进入静态网页，不能存放秘密。
3. 执行 `npm run dev` 可本地查看；缺少公开字段会在帮助 / 隐私页明确显示“未配置”。`npm run build` 在 pilot 模式缺少任一字段时失败，防止把未配置页面当作已可发布服务。构建校验只检查字段非空，不证明主体、联系方式或执行流程真实有效；发布前仍须人工核验。
4. 后端须启用独立的 pilot 配置，并由维护者仅在服务端设置注册开关 / 体验码。**绝不添加任何 VITE_* 注册码或内部 token，也不要把体验码写入源码、缓存、截图或日志。** 注册时由用户输入体验码和确认密码；确认密码只在客户端核对。敏感输入在提交结束、切换页面或隐藏页面时清空。
5. 环境变量为构建时配置，修改后须重启开发服务或重新构建；不能只修改静态服务容器运行时环境就改变已构建的页面。

pilot 登录 / 注册完成并通过 `/auth/me` 后直接进入 `/recognize`。默认个人空间只取服务端验证过的 `defaultWorkspaceId`，再读取空间详情核验成员资格；缺失 / 不可访问时不回退到其他空间。隐藏 `/home`、`/assets`、`/usage`、`/training`、`/platform`，直接输入这些路由也返回画板入口；不提供创建 / 切换空间或运营入口。前端隐藏不是安全边界，后端仍须限制创建空间和核验成员。

- `/account`：`POST /api/v2/auth/password` 仅提交 `{currentPassword,newPassword}`；成功后服务器撤销该用户所有会话，再清当前会话缓存并要求重新登录。原密码错误不清会话；401 只清发出请求的会话；429 / 网络错误不自动重试。旧请求不能清除或跳转新登录。退出不是删除账号。
- 登录保留旧用户名 / 密码中的空白，不自动 trim；新注册用户名 / 密码、新密码按约定的 Unicode 空白列表拒绝，不通过 trim“修正”。
- `/help`、`/privacy` 无需登录，说明真实用途、人工找回 / 删除与维护责任。识别元数据 30 天、日志和备份 7 天仅为试用参考，由维护者执行，**不是自动清理承诺**。分享前须确认临时文件、日志、备份及清理流程。
- 结果保留数字、置信度和处理耗时；仅 pilot 折叠技术 ID / 版本。未增加图表、统计仪表盘、历史数据或训练功能。

## 本地启动

目标环境 Node.js 22+。已有依赖无需重装；初次安装按锁文件执行：

```bash
npm ci
npm run dev
```

访问 `http://127.0.0.1:5173`。Vite 仅绑定本机，`/api` 转发到 `http://127.0.0.1:8080`；Java 及真实推理环境的准备见 [W2 本地运行说明](../docs/W2-本地运行说明.md)。网页可以构建不代表后端、数据库或模型已就绪。

## W2 开发模式页面与权限

| 路由 | 页面 | W2 范围 |
|---|---|---|
| `/` | 公共门户 | 项目介绍、注册/登录入口 |
| `/register`、`/login` | 同平台账号 | 无预填密码，注册后个人空间 |
| `/home` | 工作空间 | 当前成员空间、创建最小空间、切换 |
| `/recognize` | PC 手写识别 | 鼠标/触摸、清空、PNG 上传、真实结果 |
| `/assets` | 公共资产 | MNIST/可信模型只读元数据与默认引用 |
| `/usage` | 本人用量 | 当前空间本人记录计数；日配额未启用 |
| `/training` | 训练参数原型 | 仅校验参数，不创建任务或曲线 |
| `/platform` | 平台运行状态 | 仅服务端确认的 SUPER_ADMIN；真实服务状态与只读配置 |

W3 的私有资产、邀请/角色管理、完整历史/反馈，以及 W4 在线训练不在本次实现内。MNIST 99.10% 是 W1 标准测试集结果，不是用户手写的线上准确率；单次识别展示的是置信度。

## 会话、空间与异步隔离

- 只使用新 `hdr_v2_token` 缓存；旧 W1 token/缓存不授予访问权。
- 登录后、刷新后的首次受保护访问以 `/api/v2/auth/me` 校验真实身份。普通 USER 可以使用识别；只有运营页要求 SUPER_ADMIN。
- 服务端对每次 API 请求检查当前会话、账号和成员状态；前端守卫不是安全边界。SUPER_ADMIN 也不自动拥有其他人的空间。
- 403/404 不无条件清除会话；401 只影响发出请求时所属的会话。网络错误不证明 token 无效。
- 会话/空间 generation、画板 revision 和请求标识隔离过期响应；切换空间、清空、重画、退出后旧 success/error/finally 不覆盖新状态。
- 识别只上传 `image`、`source=WEB` 和 UUID `Idempotency-Key`；没有任意模型路径，也不自动重发识别 POST。
- 画板 Pointer Events 逻辑覆盖 DPR、单点/笔画、捕获/取消、白底 PNG、空白禁止提交。实际浏览器和设备输入仍须单列验收。
