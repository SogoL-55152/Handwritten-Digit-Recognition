# 导入图片识别修复与基线切换（adaptive-mnist-v2）

> 2026-11-07。面向 M1–M5。本页记录"导入图片识别为什么坏、怎么修、实测数字、以及哪些结论仍不能宣称"。

## 1. 根因：两个独立缺陷

**缺陷一（预处理，主因）**：旧实现只用"边框亮度中位数"判断黑底/白底，再按固定 `>=32/255` 取墨迹。相册照片的纸面是中间灰、笔迹只比纸面深一点时，整幅纸面都高于阈值 → 外接框变成整张照片 → 数字被缩到十几个像素。实测那张"3"的照片：**墨迹覆盖率 81%**，模型看到的是一个浅灰方块。

**缺陷二（模型，次因）**：训练数据只有 MNIST（原始 28×28、干净白底），从未见过纸面底色、光照渐变、低对比笔迹、模糊与 JPEG 伪影，因此即使预处理正确，照片域准确率也仅 **38.7%**。

## 2. 修复

### 预处理 `canvas-mnist-v1` → `adaptive-mnist-v2`

- 用**相对背景的归一化偏离**替代固定阈值：0 = 背景，1 = 最深/最亮的墨迹；
- 背景取两个候选——全图中位数（背景占多数，如整幅纸面）与边框中位数（数字占满画面但四周留白）——**选前景覆盖更小的那个**（数字总比背景小，覆盖过大说明把背景当墨迹）；
- 覆盖率仍 > 60% 时退到**逐像素模糊背景**（大半径，避免削薄粗笔画）并逐级抬高阈值；
- 白底黑字、黑底白字、灰纸浅笔走同一条对称路径（新增极性等价回归测试）；
- 训练脚本直接 `from services.inference_preprocess import canvas_input`，**训练与线上逐像素同源**，不再有归一化漂移。

效果（那张"3"）：墨迹覆盖率 81% → 10.6%，模型 top-1 由 `2(0.289)` 变为 `3(0.607)`。

### 训练数据与增广

- 新增**官方 EMNIST digits**（NIST `gzip.zip`，240,000 训练 / 40,000 测试，不同书写者的真实手写）：只用 digits 划分，按官方转置约定读取（已用样例目视核对字向）；
- 训练集 = MNIST 30,000 + EMNIST 30,000；
- 增广两套：画板风格（大画布、粗笔画 0–3px、±12°、0.55–0.95 缩放）+ **照片风格**（纸面底色 110–240、光照渐变 ±30%、笔迹亮度比 0.15–0.70、模糊、高斯噪声、JPEG quality 40–85、±8°）；
- 每个样本渲染后都过一遍线上 `canvas_input`，所以训练看到的就是线上看到的。

## 3. 实测结果

运行环境：Python 3.11.16 + torch CPU；CPU 3 epoch、60,000 样本、batch 64、lr 1e-3、seed 20261107、2 线程；从上一版基线增量训练，全程约 5 分钟。

| 指标（1000 张/项） | W1 基线 | 上一版（画板域） | **现基线** |
|---|---|---|---|
| MNIST test 直喂 | 98.9% | 98.6% | 97.7% |
| 画板风格模拟集 | 92.1% | 98.3% | **99.1%** |
| 照片风格模拟集 | — | 38.7% | **84.0%** |
| EMNIST digits 未见书写者（画板风格） | — | — | **98.5%** |
| 生产链路 MNIST 拒识率（0.90/0.85） | 14.2% | 5.3% | 3.8% |
| 照片模拟集：覆盖率 / 接受后正确率 | — | — | 63.1% / 99.37% |

## 4. 阈值决定（尚未放宽）

照片域在 0.90/0.85 下只覆盖 63.1%；放宽到 0.70/0.50 可到 73.8%，接受后正确率 98.2%。这是产品取舍，本轮**未改动**：宁可诚实拒识，也不在没有真实照片标定集时放松。若要放宽，建议先收集真实相册样本再定。

## 5. 不能宣称的

- 画板/照片模拟集与训练增广同源，84.0% / 99.1% **偏乐观**；MNIST 与 EMNIST 都是域内指标。
- **没有任何真实相册照片的准确率结论**；那张"3"仍被拒识（类别正确、分数 0.607）。
- 项目"真实手写 ≥90%"的目标仍未验证，仍需 W3 自采数据（画板 + 相册两类）。
- 复杂背景照片（桌面、阴影、倾斜透视、多数字）不在承诺范围；当前只支持单字、建议白底黑字。
- EMNIST 只用了 digits 划分，没有用 letters/balanced，也没有做书写者级划分的独立评估。

## 7. 复现

```text
python -I train_canvas_aug.py --data-dir data/MNIST/raw --emnist-zip <本地>/gzip.zip \
  --output-dir weights/w2-canvas-photo --init <上一版 checkpoint> \
  --epochs 3 --samples 60000 --photo-ratio 0.5 --seed 20261107 --threads 2
```

产出 `checkpoint.pt` 的 SHA-256 必须为 `72e27abd…`、大小 1,690,340 字节，否则服务按"可信基线未就绪"返回 503（fail closed，不做降级）。
