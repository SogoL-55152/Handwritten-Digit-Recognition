# 小程序 · 本周改动兼容性核对（2026-11-19）

> 本周后端改动集中在数据集、导入、训练与监控，**没有改动识别与采集的接口契约**。
> 本文记录小程序端实际依赖的接口、字段核对结果，以及哪些改动不涉及小程序。

## 1. 小程序端实际调用的接口

| 场景 | 方法与路径 | 关键字段 |
|---|---|---|
| 登录 | `POST /api/v2/auth/login` | `token`、`user`、`defaultWorkspaceId` |
| 会话校验 | `GET /api/v2/auth/me` | `user`、`defaultWorkspaceId` |
| 空间列表 | `GET /api/v2/workspaces` | `id`、`name`、`role`、`status`、`defaultModelId` |
| 单字识别 | `GET /recognitions/request-id` → `POST /recognitions` | `Idempotency-Key` 头 + `source=MINIPROGRAM` |
| 多位数 | `POST /recognitions/multi` | `source`、`maxDigits` |
| 多位数预览 | `POST /recognitions/multi-preview` | 同上 |
| 改密 | `POST /api/v2/auth/password` | `currentPassword`、`newPassword` |
| 登出 | `POST /api/v2/auth/logout` | — |

小程序**不调用**采集样本、数据集、训练任务相关接口；本周这些改动不影响它。

## 2. 契约核对结果

### 单字识别响应

小程序 `validateResult` 要求：`requestId`、`recognitionId`（字符串）、`digit`（0–9）、`confidence`（0–1）、`modelId`/`modelVersion`/`preprocessVersion`、`source=MINIPROGRAM`、`processingMs`、`createdAt`。

实测响应：

```json
{"recognitionId":"479","requestId":"93a5…","digit":2,"confidence":0.9802,
 "modelId":"8","modelVersion":"w4-task-8-a1","preprocessVersion":"adaptive-mnist-v2",
 "source":"MINIPROGRAM","processingMs":15,"createdAt":"2026-11-19T…"}
```

→ **字段完全匹配**。

### 多位数响应

小程序 `validateMultiResult` 要求：`text`（1–4 位数字）、`digits`（长度 = text 长度，每项 `digit/confidence/margin/left/right`）、`accepted`（布尔）、同上的模型与时间字段。

实测响应键：

```
accepted, createdAt, digits, modelId, modelVersion, preprocessVersion,
processingMs, recognitionId, requestId, source, text
```

→ **字段完全匹配**。

### 错误语义

| 场景 | 返回 | 小程序处理 |
|---|---|---|
| 拒识 | 422 `UNRECOGNIZED_INPUT` | 提示重写 |
| 限流 | 429 `RATE_LIMIT` | 提示稍后重试 |
| 多位数超限 | 422 `DIGIT_LIMIT` | 提示减少一位 |
| 未登录 | 401 | 清会话回登录页 |

本周未改这些码，行为不变。

## 4. 需要你注意的两件事

1. **真机联调要改地址**：`miniprogram/config/public.js` 里是 `http://127.0.0.1:8080`，微信开发者工具可用；真机需换成局域网 IP 或公网域名，并且小程序要求 HTTPS 域名白名单。
2. **新功能不在小程序端**：数据集导入、版本、参数可视化、训练监控都是 Web 管理端能力，小程序定位仍是“画板识别 + 结果查看”。如果要在手机上看训练进度，属于新增页，不在本次兼容范围内。

## 5. 结论

本周改动**不需要修改小程序代码**：接口路径、请求格式（`Idempotency-Key` + `source=MINIPROGRAM`）、响应字段、错误码均未变化，单测与真实调用都通过。
