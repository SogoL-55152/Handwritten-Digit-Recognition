## 2. 关键用例（骨架阶段）

### 2.1 认证

- 正确账号密码登录返回 token。
- 错误密码返回 400/401，提示不泄露用户是否存在。
- 无 token 访问受保护接口返回 401。
- 普通用户访问管理员接口返回 403。

### 2.2 预处理（自动化）

- 白底黑字与黑底白字均能正确反色。
- 空白图片抛出"无可识别笔画"。
- 输出形状为 `(1, 1, 28, 28)`，数值已完成标准化。
- 不同尺寸输入均居中缩放，长宽比保持。

### 2.3 模型管理

- 同一时刻仅一个 `is_active=1`。
- 活跃模型不可删除。
- 切换模型后 Flask 注册表活跃 ID 同步更新。

### 2.4 训练

- 创建任务后状态从 PENDING → RUNNING → SUCCESS。
- 训练曲线指标单调追加，进度递增。
- 训练成功后模型自动出现在模型列表。
- 模型服务不可用时创建任务返回 502 且任务标记 FAILED。

### 2.5 识别

- 单字 0–9 各 20 个自采样本，统计准确率 ≥ 90%。
- 空白画板给出明确错误提示。
- 超过 5 MB 图片被拒绝。

## 3. 测试数据

- MNIST 测试集：仅作回归参考，不作为验收依据。
- 自采数据集：W3 起采集 ≥ 1000 样本，按 7:3 划分调优/测试，覆盖不同书写风格与设备。

## 4. 缺陷分级
