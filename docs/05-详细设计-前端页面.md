# 05 详细设计 · 前端页面

| 项 | 值 |
|---|---|
| 文档版本 | v1.0 |
| 技术栈 | Vue 3 + Vite 6 + Vue Router + ECharts（按需引入） |
| 生成方式 | 按 `frontend/src` 实际路由与页面整理 |
| 生成日期 | 2026-11-19 |

## 1. 整体结构

```
views/            页面（14 个）
layout/           AdminLayout（侧栏 + 顶栏 + 空间切换）
stores/           user（登录态）、workspace（当前空间 + 成员）
api/              request.js（axios 封装）+ 9 个领域模块
training/         训练相关组件（曲线、矩阵、详情、step 曲线）
wizard/           参数可视化 schema、估算、结构图
datasets/         导入相关纯函数（分卷、进度文案）
```

## 2. 路由与页面

| 路径 | 页面 | 权限 | 职责 |
|---|---|---|---|
| `/` | Portal | 公开 | 入口介绍，跳登录或工作台 |
| `/login`、`/register` | Login | 公开 | 登录 / 注册 |
| `/help`、`/privacy` | Support | 公开 | 帮助与隐私说明 |
| `/home` | Home | 登录 | 工作空间概览 |
| `/recognize` | Recognize | 登录 | 画板/拍照识别、多位数、结果上报 |
| `/account` | Account | 登录 | 账号与密码 |
| `/assets` | Assets | 登录 | 公共资产（基线模型、公共数据集） |
| `/datasets` | Datasets | 登录 | 数据集、版本、导入、样本管理 |
| `/usage` | Usage | 登录 | 空间用量 |
| `/training` | Training | 登录 | 训练记录、曲线回放、日志、详情 |
| `/statistics` | Statistics | 登录 | 调用量、拒识、模型分布 |
| `/wizard` | TrainingWizard | **SUPER_ADMIN** | 参数可视化四步：选数据→调参→监控→评估 |
| `/models` | Models | **SUPER_ADMIN** | 模型注册、激活、停用、删除 |
| `/platform` | Platform | **SUPER_ADMIN** | 服务健康、队列、配额 |

导航由 `navigationLinks()` 生成：普通用户看不到 `/wizard`、`/models`、`/platform`；
`meta.superAdmin` 由路由守卫二次校验，直接输 URL 也会被拦回。

## 3. 状态管理

| store | 内容 | 关键行为 |
|---|---|---|
| `user` | 令牌、用户信息、`platformRole` | 登录/登出、`getSnapshot()` 给请求层、401 时清会话 |
| `workspace` | 当前空间、成员角色、`active` | 启动时拉列表并核验；`active` 就绪前不发业务请求 |

**约定**：任何依赖 `workspaceId` 的页面，必须等 `workspace.active` 有值再加载，
否则会出现 `workspaceId=0` 导致「空间不存在或不可访问」（本周已修）。

## 4. 请求层约定

| 项 | 约定 |
|---|---|
| 基址 | `/api/v2`（Vite 代理到后端 8080） |
| 鉴权 | 拦截器自动加 `Authorization: Bearer <token>` |
| 包装 | 成功返回 `data`；`code != 0` 抛出带 `message/status/data` 的错误 |
| silent | 页面自己处理错误时传 `silent: true`，不触发全局提示 |
| 超时 | 默认 20s；导入/训练提交单独 600s |
| 401 | 非 silent 时清会话并跳登录 |

## 5. 关键页面状态机

### 5.1 数据集页（`/datasets`）

```
未选数据集 ──选中──▶ 数据集详情
数据集详情 ├─ 导入图片（选文件夹，逐张上传）
           ├─ 导入数据集（目录 / zip → 试运行 → 确认）
           ├─ 建版本（版本号 + 验证/测试比例 + 来源）
           ├─ 归入识别采集（把无归属样本挂到本数据集）
           └─ 删除数据集 / 删除版本 / 删除样本
```

| 状态 | 含义 | UI 表现 |
|---|---|---|
| `state.loading` | 加载中 | 骨架/禁用按钮 |
| `state.busy` | 有写操作在跑 | 全部写按钮禁用 |
| `state.notice` | 成功提示 | 绿色提示条 |
| `state.error` | 失败提示 | 红色提示条（含服务端 message） |
| `state.wizard.preview` | 试运行结果 | 格式、数量、标签分布、跳过原因、自检 |

### 5.2 参数可视化（`/wizard`）

| 步 | 内容 | 数据来源 | 出参 |
|---|---|---|---|
| ① 选数据 | 选数据集与版本，看划分与样本缩略图 | `listDatasets` / `listVersions` / `versionStats` | `config.datasetVersionId` |
| ② 调参 | schema 表单 + 实时估算 + 模板 | 本地 `schema.js` / `estimate.js` | `config`、`configHash` |
| ③ 监控 | 任务列表、逐轮/step 曲线、日志、早停 | `createTask` / `listTasks` / `trainingLogs` | `state.taskId` |
| ④ 评估 | 指标卡片、混淆矩阵、每类准确率 | 任务 `metrics` | 只读 |

```
step=1 ──下一步──▶ step=2 ──开始训练──▶ 提交任务 → step=3
step=2 ◀──上一步──  step=3 ──下一步──▶ step=4
step=2 有阻塞校验时禁止提交（blocking）
```

**参数生效边界**：epochs / samples / batchSize / lr / seed / photoRatio / 早停 / 版本 / 微调起点真实生效；
网络结构、优化器、学习率调度、AMP 只参与估算，界面标「仅估算」。

### 5.3 训练记录页（`/training`）

| 状态 | 表现 |
|---|---|
| 列表轮询 | 有 QUEUED/RUNNING 任务时 3–4 秒刷新，全部结束自动停 |
| SSE | 连接成功用推送更新，断线退化为轮询 |
| 展开曲线 | 逐轮曲线 + step 曲线 + 详情 + 混淆矩阵 |
| 展开日志 | 读一次，训练中每 3 秒刷新，结束停止 |

## 6. 组件清单

| 组件 | 用途 |
|---|---|
| `TrainingCurve` | 逐轮损失与三域准确率 |
| `StepCurve` | step 级损失 + 学习率 |
| `TrainingDetail` | 参数卡、逐轮表、早停提示 |
| `TrainingMatrix` | 混淆矩阵与每类准确率 |
| `NetDiagram` | 网络结构图（参数可视化） |
| 参数表单 | 由 `schema.js` 驱动：slider / select / switch / 层编辑器 |

## 7. 交互约定

| 场景 | 约定 |
|---|---|
| 删除样本 | 不弹确认，直接删 + 提示 |
| 删除版本 / 数据集 | 服务端校验引用，失败直接显示原因（409） |
| 长任务 | 显示「处理中…」，按钮禁用，避免重复提交 |
| 空状态 | 每个列表都有明确空态文案 + 下一步入口 |
| 数字格式 | 参数量千分位、耗时按 s/m 自适应、准确率保留 1 位小数 |

## 8. 已知限制

| 限制 | 影响 |
|---|---|
| 大文件导入同步等待 | 页面停留时间长，无进度条（P1 做异步进度） |
| 参数可视化整页仅管理员 | 普通用户无法自助调参 |
| 无全局草稿 | 刷新后参数配置丢失（草稿待做） |
