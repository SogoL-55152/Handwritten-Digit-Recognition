# 手写数字识别系统 — 接口契约 v1.0

> 编制：M1　|　日期：2026-10-24　|　状态：待团队评审确认（周四前完成）
>
> 以本文件为准。Java 后端面向前端，路径前缀 `/api`；Flask 面向前端，路径前缀 `/api/v1`。
> OpenAPI 初稿见 [`docs/api/openapi.yaml`](api/openapi.yaml)。
>
> **实现范围说明**：契约描述目标形态；当前 `develop` 骨架只实现第 2.1 节认证与健康检查，
> 其余接口由各成员在各自 `feature/*` 分支按本契约实现。

## 1. 通用约定

### 1.1 响应格式

```json
{ "code": 0, "message": "ok", "data": {} }
```

| code | 含义 |
|---|---|
| 0 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 / token 失效 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |
| 502 | 模型服务异常 |

> HTTP 状态码在骨架阶段统一为 200（除未捕获异常外），业务结果以 `code` 判断。

### 1.2 鉴权

- 除 `POST /api/auth/login`、`POST /api/auth/register`、`GET /api/health` 外，均需请求头：
  `Authorization: Bearer <token>`
- Token 有效期默认 24h，载荷包含 `sub`（用户 ID）、`username`、`role`。

### 1.3 分页

请求参数：`page`（从 1 开始，默认 1）、`size`（默认 10）。响应 `data`：

```json
{ "records": [], "total": 0, "page": 1, "size": 10 }
```

## 2. 业务后端接口（Spring Boot）

### 2.1 认证

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/auth/register` | 公开 | 注册普通用户 |
| POST | `/api/auth/login` | 公开 | 登录，返回 token |
| GET | `/api/auth/me` | 登录 | 当前用户信息 |
| GET | `/api/health` | 公开 | 健康检查 |

`POST /api/auth/register`

```json
{ "username": "alice", "password": "123456", "nickname": "Alice" }
```

`POST /api/auth/login` → `data`

```json
{
  "token": "eyJ...",
  "user": { "id": 1, "username": "admin", "nickname": "管理员", "role": "ADMIN", "status": 1 }
}
```

### 2.2 用户管理（ADMIN）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/users?page=1&size=10&keyword=` | 分页查询（用户名/昵称模糊） |
| PUT | `/api/users/{id}/status` | 启用/停用，body `{ "status": 0 }` |

### 2.3 模型管理

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/models?page=1&size=10` | 登录 | 模型分页 |
| GET | `/api/models/active` | 登录 | 当前活跃模型，可为 null |
| POST | `/api/models/{id}/activate` | ADMIN | 切换活跃模型（同步 Flask） |
| DELETE | `/api/models/{id}` | ADMIN | 删除模型（活跃模型不可删） |

模型对象：

```json
{
  "id": 3, "name": "cnn-v1", "version": "20261022-153000",
  "externalId": "ab12...", "filePath": "/app/weights/ab12.pt",
  "accuracy": 0.9821, "active": 1, "description": "训练任务 #12 产出",
  "createdAt": "2026-10-22T15:30:00"
}
```

### 2.4 数据集管理

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/api/datasets?page=1&size=10` | 登录 | 数据集分页 |
| POST | `/api/datasets` | ADMIN | 新建数据集元数据 |

```json
{ "name": "MNIST", "type": "MNIST", "sampleCount": 70000, "storagePath": "data/mnist", "description": "内置数据集" }
```

### 2.5 训练任务

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/train-tasks` | ADMIN | 创建并启动训练 |
| GET | `/api/train-tasks?page=1&size=10` | 登录 | 任务分页 |
| GET | `/api/train-tasks/{id}` | 登录 | 任务详情 |
| GET | `/api/train-tasks/{id}/metrics` | 登录 | 训练状态与指标（前端 2s 轮询） |

创建请求：

```json
{
  "name": "cnn-实验一",
  "datasetId": 1,
  "modelName": "cnn-v1",
  "params": { "epochs": 3, "batchSize": 128, "learningRate": 0.001 }
}
```

`metrics` 响应：

```json
{
  "status": "RUNNING",
  "progress": 66,
  "epoch": 2,
  "metrics": [
    { "epoch": 1, "loss": 0.1243, "accuracy": 0.9612 }
  ],
  "model": null
}
```

训练成功后 `model` 字段：

```json
{ "id": "ab12...", "name": "cnn-v1", "path": "/app/weights/ab12.pt", "accuracy": 0.9821 }
```

### 2.6 识别

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/api/recognition/predict` | 登录 | `multipart/form-data`，字段 `file` |

响应 `data`：

```json
{ "result": "7", "confidence": 0.9931, "modelName": "cnn-v1", "costMs": 87 }
```

### 2.7 统计

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/stats/overview` | `{ userCount, modelCount, callCount, accuracy, activeModel }` |
| GET | `/api/stats/call-trend` | `[{ "date": "2026-10-22", "count": 12 }]` |

## 3. 模型服务接口（Flask，内部）

### 3.1 健康检查

`GET /api/v1/health` → `{ "status": "UP" }`（骨架阶段；接入 PyTorch 后增加 `torchAvailable` 字段）

### 3.2 推理

`POST /api/v1/predict`（multipart：`file`；可选 query `model_id`）→

```json
{ "code": 0, "message": "ok", "data": { "result": "7", "confidence": 0.9931, "model_id": "ab12", "model_name": "cnn-v1" } }
```

### 3.3 模型注册表

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/models` | 已注册模型列表与活跃 ID |
| POST | `/api/v1/models/{model_id}/activate` | 激活模型并持久化 |

### 3.4 训练

`POST /api/v1/train`

```json
{
  "task_id": "3f2a...",
  "model_name": "cnn-v1",
  "dataset": "MNIST",
  "params": { "epochs": 3, "batchSize": 128, "learningRate": 0.001 }
}
```

→ `{ "code": 0, "data": { "task_id": "3f2a..." } }`

`GET /api/v1/train/{task_id}` → `data` 内容：

```json
{
  "status": "RUNNING", "progress": 66, "epoch": 2,
  "metrics": [{ "epoch": 1, "loss": 0.1243, "accuracy": 0.9612 }],
  "model": null, "error": null
}
```

> Flask 所有接口均使用统一响应包裹；Spring Boot 客户端会自动取出 `data`。

状态机：`PENDING → RUNNING → SUCCESS | FAILED`。
