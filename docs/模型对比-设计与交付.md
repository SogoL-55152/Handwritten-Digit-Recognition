# 模型版本对比（并排指标 + 差异样本）

> 对应交接文档 P1-8：「模型对比（两个版本并排指标、差异样本）——模型管理页目前只能激活/停用」
> 完成日期：2026-11-25

---

## 1. 设计

对比要回答两个不同的问题，页面分两块：

| 问题 | 数据来源 | 是否可直接横比 |
|---|---|---|
| 这两个版本各自训练时表现如何？ | `t_v2_training_task.metrics`（P1-7 的三域指标） | ❌ 各自的评估集不同，只能参考 |
| 在同一批带标签样本上，谁更好？ | 本次用两个模型**同跑**这批样本 | ✅ 同一输入，唯一可比的数字 |

### 1.1 调用链

```
模型管理页「对比模型」
  → POST /api/v2/admin/models/compare     {versionA, versionB, datasetVersionId, limit}
  → ModelCompareService
       ├─ 校验 SUPER_ADMIN、数据集版本归属（要求调用方是该工作空间成员）
       ├─ 取该版本的带标签样本（label ∈ 0..9），读原图（≤512KB/张）
       ├─ 模型服务 POST /internal/v2/compare  （multipart，多图 + labels）
       └─ 补上两个版本的元数据与各自训练指标（只取 after / macro / bestEpoch，避免整份 metrics）
```

### 1.2 模型服务 `/internal/v2/compare`

- 表单：`modelAId/modelAVersion/modelAPreprocess`、`modelBId/modelBVersion/modelBPreprocess`、`labels`（逗号分隔，`-1` 表示无标签）
- 文件：`image` 重复 1..200 张；总请求上限 32MB，part 数 216
- 两个模型都必须**在注册表里且摘要校验通过**（`MODEL_NOT_ALLOWED` 否则 400）
- 逐张算 `probabilities()`（**原始概率，不经过选择性识别策略**）——对比的是模型本身，不是"模型 + 阈值"
- 逐张占用/释放推理槽；槽满 → 429 `MODEL_BUSY`
- 返回每张的 `digitA/confidenceA/digitB/confidenceB/agree` + 汇总

汇总字段：`samples / labelled / agreement / agreementRate / accuracyA / accuracyB /
bothRight / onlyA / onlyB / bothWrong / meanConfidenceA / meanConfidenceB`。

### 1.3 前端

`frontend/src/models/ModelCompare.vue`（纯逻辑在 `frontend/src/models/compare.js`）：

- 两个模型下拉 + 数据集版本下拉（`GET /dataset-versions`，默认选第一个有样本的 READY 版本）+ 样本数（1..200）；
- 结论条：`共 100 张样本；一致 90 张（90.0%）；A 正确率 99.0%，B 正确率 91.0%；…；A 高 8.0 个百分点`；
- 元数据并排表（版本/状态/来源/预处理/登记准确率/注册表状态/训练完成/摘要前 8 位）；
- 训练时的三域指标并排（明确标注"各自评估集不同，不能直接横比"）；
- 差异样本列表：缩略图（走已有的样本图片接口）+ 真值 + A/B 的判定与置信度 + `A 对 / B 对 / 都错 / 无标签` 徽标。

## 3. 过程中修的 bug（值得记录）

`t_v2_dataset_sample.label` 是 **VARCHAR**（不是数字列）。第一版实现直接 `(Number) row.get("label")` 强转，
运行期抛 `ClassCastException`；而这个异常被"单张样本读不到就跳过"的 `catch` 吞掉，
**但图片已经加进列表、标签没有**，于是模型服务收到 `images.length != labels.length`，
用户看到的是"对比图片与标签数量必须一致"——一个和真实原因毫无关系的报错。

修法：先把 `label`、`artifact_path` 都取齐再统一入列，并加 `labelOf()` 兼容字符串/数字，
另加 `ModelCompareLabelTest` 锁住解析行为。

## 4. 已知局限

1. **样本来自数据集版本**：没有版本就没法对比；对比评估使用的样本可能与该模型的训练集重叠（页面不校验），
   要避免自评请选一个训练时没用过的版本。
2. **只支持单字**：多位数样本（`label_text`）不参与对比。
3. **同步请求**：100 张约 4s，200 张约 8s；再大就应改成后台任务（与 P1-10「导入异步化」同一类改造）。
4. **不落库**：对比结果不保存，刷新即丢；需要留证据请截图或另存。
5. **缩略图走样本图片接口**：需要调用方对该工作空间有成员权限（当前就是如此，故未额外放权）。
