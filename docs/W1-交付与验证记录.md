## 3. 主要实现

### M1

- 复用已有需求、架构、接口和规范文档，不恢复历史完整业务实现。
- 区分 W1 实际功能与未来目标；Flask 仅在内网由 Java 调用。
- 对齐认证字段约束、统一响应和 HTTP/业务码语义，修正内部服务地址及健康响应说明。
- CI 不再跳过 Java 测试，并随各成员分支分别加入前端、小程序和无模型依赖的训练参数检查；常规 CI 不下载 MNIST 或训练模型。
- Wiki 作为协作入口，本次将仓库 `docs/` 与模块指南手工同步到 Wiki；两者仍不自动同步。需求确认表保留原有待确认项，不代签。

### M2

- 注册唯一键竞争返回业务 400，不把重复用户名作为服务器错误。
- 管理员校验通过后才写用户上下文，避免拒绝路径泄漏 ThreadLocal；非法 JWT subject 返回认证失败。
- 保留固定 `ADMIN/USER` 单角色设计，不新增 RBAC 或 W2 用户管理 CRUD。
- 数据库字典对齐现有五表和 52 个字段；ER 明确是逻辑关系，不冒充已有数据库外键、唯一活跃模型等约束。

### M3

- 独立 CLI，默认不联网，支持 CPU、seed、epoch、样本限制、路径和显式下载。
- MNIST 数据通过标准 IDX 流程加载，不使用旧 pickle 数据缓存。
- 保存最后一轮权重并验证重载输出，记录环境、数据规模、逐轮指标和耗时，不按测试集挑选最佳 checkpoint。
- 真实子集 smoke 与全量基线都已运行，见 [MNIST 基线记录](https://github.com/SogoL-55152/Handwritten-Digit-Recognition/blob/feature/m3-w1/docs/W1-MNIST基线训练记录.md)。**MNIST 99.10% 不等于真实画板准确率。**

### M4

- 首次保护路由/登录后通过 `/auth/me` 核验，不信任本地缓存角色。
- 普通用户拒绝进入；失效会话清理；网络失败保留凭证但不放行未核验会话。
- 并发核验去重，旧请求不能在登出/新登录后覆盖状态；返回地址限制为站内受保护路由。
- 移除登录预填密码，将准确率文案标为项目目标。

### M5

- Canvas 2D、DPR、单点与连续笔画、取消触摸、白底 PNG 导出预览、清空及错误提示。
- 通过版本标记防止旧导出回调污染清空/重画后的状态。
- 独立 W1 原型页不依赖后端，不发识别请求，不伪造识别结果，也不放松业务首页鉴权。
- token/user 缓存统一读取与清理，消除半份缓存造成的登录/首页循环跳转。
