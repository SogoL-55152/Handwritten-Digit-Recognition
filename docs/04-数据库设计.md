# 手写数字识别系统 — 数据库设计 v0.1

> 数据库：MySQL 8.0，字符集 `utf8mb4`。DDL 见 `backend/src/main/resources/db/schema.sql`。

## 1. ER 关系

```
t_user 1 ──── n t_recognition_log
t_model 1 ─── n t_recognition_log
t_dataset 1 ── n t_train_task
t_model 1 ─── 0..1 t_train_task（训练成功后回填 model_id）
```

## 2. 表结构

### 2.1 用户 t_user

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK, AUTO_INCREMENT | |
| username | VARCHAR(64) | UNIQUE, NOT NULL | 登录名 |
| password | VARCHAR(100) | NOT NULL | BCrypt 哈希 |
| nickname | VARCHAR(64) | | 昵称 |
| role | VARCHAR(16) | NOT NULL, 默认 USER | ADMIN / USER |
| status | TINYINT | NOT NULL, 默认 1 | 1 启用 / 0 停用 |
| created_at | DATETIME | 默认 CURRENT_TIMESTAMP | |
| updated_at | DATETIME | 自动更新 | |
| deleted | TINYINT | 默认 0 | 逻辑删除 |

### 2.2 模型 t_model

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT | PK | |
| name | VARCHAR(64) | NOT NULL | 展示名 |
| version | VARCHAR(64) | | 版本/时间戳 |
| external_id | VARCHAR(64) | UNIQUE | 模型服务中的 ID |
| file_path | VARCHAR(255) | | 权重路径 |
| accuracy | DOUBLE | | 验证集准确率 |
| is_active | TINYINT | 默认 0 | 全局唯一活跃 |
| description | VARCHAR(255) | | |
| created_by | BIGINT | | 创建人 |
| created_at / updated_at / deleted | | | 同用户表 |

> 活跃唯一性由服务层保证（事务内先清零再置 1）。

### 2.3 数据集 t_dataset

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | PK |
| name | VARCHAR(64) | 名称 |
| type | VARCHAR(16) | MNIST / CUSTOM |
| sample_count | INT | 样本数 |
| storage_path | VARCHAR(255) | 数据路径 |
| description | VARCHAR(255) | |
| created_at / updated_at / deleted | | |

### 2.4 训练任务 t_train_task

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | PK |
| name | VARCHAR(64) | 任务名 |
| dataset_id | BIGINT | 关联数据集 |
| model_name | VARCHAR(64) | 产出模型名 |
| params_json | TEXT | 超参数 JSON |
| status | VARCHAR(16) | PENDING/RUNNING/SUCCESS/FAILED |
| progress | INT | 0–100 |
| external_task_id | VARCHAR(64) | Celery/模型服务任务 ID |
| model_id | BIGINT | 训练产出的模型 |
| error_msg | VARCHAR(500) | 失败原因 |
| created_by | BIGINT | |
| created_at / updated_at / deleted | | |

### 2.5 识别日志 t_recognition_log

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | PK |
| user_id | BIGINT | 调用用户 |
| model_id | BIGINT | 使用的业务模型 |
| result | VARCHAR(64) | 识别结果（连续识别时为字符串） |
| confidence | DOUBLE | 置信度 0–1 |
| cost_ms | INT | 服务端耗时 |
| image_path | VARCHAR(255) | 可选，原图留存 |
| created_at | DATETIME | 统计维度 |

索引：`idx_created_at(created_at)`、`idx_model_id(model_id)`、`idx_user_id(user_id)`。

## 3. 初始化数据

应用启动时 `DataInitializer` 自动创建：

- 管理员：`admin / admin123`（角色 ADMIN）
- 内置数据集：`MNIST`，类型 MNIST，70000 样本

> 生产环境务必修改默认密码，并替换 `JWT_SECRET`。
