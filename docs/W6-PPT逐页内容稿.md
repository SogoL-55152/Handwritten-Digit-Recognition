## P4 准确率现状（全篇最重要）

- **标题**：瓶颈不在切分，在逐位识别
- **结论条**：切分精确率 99–100%，逐位只有 95.5%
- **主表格**（照抄）：

| 位数 | 整串正确率 | 逐位正确率 | 切分精确率 |
|---|---|---|---|
| 1 位 | 97.5% | 97.5% | 100% |
| 2 位 | 91.7% | 95.4% | 99.2% |
| 3 位 | **86.7%** | 95.6% | 100% |
| 4 位 | 85.8% | 96.3% | 100% |

- **换算条**（单独一行，加粗）：
  整串 ≈ 逐位^N → 3 位要过 90%，逐位需 ≥96.5%，现在差 1 个点
- **备注小字**：每档 120 组，样本来自 20,074 条真实触屏笔迹
- **讲稿**（70 秒）：
  这是全篇最关键的一页。切分几乎不丢分，99 到 100%；真正卡住的是逐位准确率 95.5%。整串正确率约等于逐位准确率的 N 次方，所以 3 位要过 90%，逐位得做到 96.5%，我们差一个点。差距是明确的、可量化的。
- **版面**：表格占 70% 宽，右下一行加粗换算条；3 位那一行用强调色。

## P5 数据闭环

- **标题**：让用户告诉我们对不对
- **结论条**：模型预测不能当标签——它会错，而且错得自信
- **证据条**：曾把 9 判成 7，置信度 0.976
- **三种标注**（三列卡片）：
  - 单字点选：错了点正确的 0–9
  - 多位确认：✓ 对，就是 351（一键）
  - 多位纠正：✗ 不对，我来输入
- **设计约束**（3 条）：
  - 未勾选同意一律不保存（数据库 `CHECK (consent=1)`）
  - 同图摘要去重，不重复入库
  - 只本人可见，无跨用户列表
- **数据条**：累计识别 **326** 条 ｜ 采集样本 **38** 条（多位数 10 条）
- **讲稿**（60 秒）：
  模型会错，而且错得自信，所以标签必须由用户给。我们做了三种标注方式：单字点选、整串一键确认、整串手输纠正。采集时同时存下模型当时的判断，因此能直接区分"模型对"和"模型错"。目前采集了 38 条，还不够。
- **版面**：上方结论 + 证据，中部三张卡片，底部数据条。

## P6 照片预处理

- **标题**：先修输入，再谈模型
- **结论条**：真实照片从 3/6 提到 5/6
- **对比表**（照抄）：

| 指标 | 处理前 | 处理后 |
|---|---|---|
| 识别正确 | 3/6 | **5/6** |
| 被接受（过阈值） | 2/6 | **5/6** |

- **处理链**（4 步）：光照归一化 → Otsu 二值化 → 闭运算 + 加粗（1–4px）→ 白底黑字
- **副作用修复**（1 条）：JDK 缺色彩管理库导致 CMYK/ICC 照片直接 500 → 改为容器级放行、交给 Python 判定
- **配图**：左侧放「处理前」照片，右侧放「处理后」白底黑字图（同一张）
- **讲稿**（60 秒）：
  真实照片有阴影和纸纹，直接送模型会把阴影当墨迹。我们加了光照归一化、二值化和按比例加粗，六张实拍照片从对 3 张提到对 5 张。顺带修了一个真问题：某些照片会让 Java 直接报 500，现在能正常识别了。
- **版面**：上半对比表，下半左图右图对比。

## 制作规范

### 全局

- 比例 **16:9**，共 **10 页**，汇报 **8–10 分钟**
- 每页文字上限：**1 个标题 + 1 个结论条 + ≤6 条要点**（表格不算要点）
- 标题字号 ≥ 32pt，正文 ≥ 18pt，表格 ≥ 14pt
- 配色：深蓝主色 + 灰底，状态色仅用绿（✅）/ 红（❌）/ 橙（强调）
- 数字统一用**阿拉伯数字 + 百分号一位小数**（如 86.7%）

### 禁止

- 不要写"每个人各自做了什么"（按汇报要求）
- 不要出现没有来源的准确率或百分比
- 不要把 1/2/3/4 位准确率合并成一个平均数
- 不要写"已达标"或"准确率 90%+"——当前是 86.7%

### 口径说明（若被问）

- 分位准确率来自**合成串**：用 20,074 条真实触屏笔迹按画板规则渲染，每档 120 组
- 照片增强对比来自**6 张实拍照片**，同一模型、同一策略阈值
- 单测数量为当前 `develop` 分支实跑结果

### 可选加页（不加也行）

- 若现场有人问"切分具体怎么做"：补一张示意图，标注「投影曲线 / 空隙阈值 2% / 每段 28×28」
- 若问"为什么没上 CTC"：一句话——连笔需要序列模型，工期与数据都是数量级差异，已列入 W9 可行性探索
