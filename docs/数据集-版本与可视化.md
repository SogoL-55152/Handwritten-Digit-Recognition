# 数据集：版本、划分与可视化

> 2026-11-18。把“采集到的样本”整理成可训练、可评测的集合。版本是快照，划分默认按书写者隔离。

## 1. 为什么需要

采集库（	_collected_sample）只是散样本，训练和评测需要：

- **固定快照**：今天训的模型，三个月后还能复现同一份数据；
- **按人划分**：同一个人不能既在训练集又在测试集，否则准确率虚高；
- **可视化**：看得出类别缺失、来源分布、样本长什么样。

## 2. 数据模型（V16）

| 表 | 作用 |
|---|---|
| 	_v2_dataset_version | 版本快照：划分方式、样本数、书写者数、val/test 比例、状态 |
| 	_v2_dataset_sample | 版本内每条样本的归属：split（TRAIN/VAL/TEST）、标签、来源、书写者 |

划分规则：

- WRITER（默认）：按书写者哈希分桶，**一个人的所有样本只落在一个划分**；
- RANDOM：按样本哈希，用于对比或书写者太少时；
- 书写者少于 3 位时，WRITER 直接拒绝并提示，避免划分退化成单侧。

## 3. 接口

`
POST /workspaces/{wid}/datasets                       建数据集
POST /workspaces/{wid}/datasets/{id}/versions          建版本（快照 + 划分）
GET  /workspaces/{wid}/datasets/{id}/versions          版本列表
GET  /workspaces/{wid}/dataset-versions/{vid}/stats    统计（标签/划分/来源/书写者泄漏）
GET  /workspaces/{wid}/dataset-versions/{vid}/samples  分页取样（split/label 过滤）
GET  .../samples/{sid}/image                           样本原图（缩略图）
`

## 4. 页面

/datasets（工作台 → 数据集）：

- 左侧数据集列表，右侧版本与样本；
- 「新建数据集」→ 填名称 → 创建；
- 选数据集 → 设置版本号、划分方式、val/test 比例、标签筛选 → **用当前样本生成版本**；
- 版本切换用胶囊标签；统计区显示训练/验证/测试数量、书写者数、标签分布条；
- 样本网格分页（每页 12 张，可按划分/标签过滤），缩略图按需加载；
- 提示区会明确写出「验证集为空」「书写者跨划分泄漏」「书写者少于 3 位」等风险。

## 6. 训练已接入版本（2026-11-18 补）

训练页新增「数据版本」下拉：

- 选中某版本后，训练任务会把该版本的 **TRAIN 划分**样本导出成 PNG 目录（	raining-data/v<版本ID>/，
  文件名形如 7_123.png + manifest.json），随任务参数传给模型服务；
- 模型服务读取这些 PNG，用线上同一条 canvas_input 归一化后**并入训练集**（不叠加照片模拟，
  因为它们本身就是真实画板/照片样本）；
- 多位数样本（标签是 351 这类）不参与单字训练，会被跳过；指标 extra_samples 记录实际并入数量；
- 任务详情/模型来源都能反查到该版本与任务号。

实测：任务 #20 使用版本 v1（47 条，TRAIN 27 条）→ 实际并入 19 条（其余为多位数样本），
任务 SUCCEEDED，产物登记为 w4-task-20-a1。
