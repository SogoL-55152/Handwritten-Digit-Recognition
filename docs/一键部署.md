# 一键部署（本机模式，无 Docker）

> 适用：Windows 10/11，没有安装 Docker 的机器。
> 入口：仓库根目录的 `deploy.bat`（或 `scripts\deploy.ps1`）。

---

## 1. 前置条件

脚本只检测、不自动安装。缺哪个会停下来并打印安装命令。

| 依赖 | 版本 | 检查 |
|---|---|---|
| JDK | 17 | `java -version` |
| Node | 20–22 | `node -v` |
| Python | 3.11 | `python --version` |
| MySQL | 8.0 | 需要 `mysqld.exe` / `mysql.exe` |
| Redis | 7 | 需要 `redis-server.exe` |

装了 Docker 的机器可以继续用 `start.bat`（Compose 模式），两者不要同时跑。

---

## 2. 启动

```bash
git clone https://github.com/SogoL-55152/Handwritten-Digit-Recognition.git
cd Handwritten-Digit-Recognition
git checkout feature/ui-polish-20261125   # 脚本所在分支
deploy.bat
```

或：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1
```

### 首次运行会做什么

1. 检测 JDK / Node / Python / Maven / MySQL / Redis 与端口
2. 生成 `scripts/.env`（随机数据库密码、JWT、内部 token、管理员密码）
3. 启动 MySQL / Redis；初始化数据目录（若为空）
4. 创建数据库（默认 `hdr_w2_it_live`）与用户 `hdr`
5. 创建 `.venv` 并安装依赖（含 torch，约 200 MB）
6. 检查权重（缺则下载）；缺 jar 则 `mvn package`，缺 node_modules 则 `npm ci`
7. 调用 `scripts/start-all.ps1` 启动 6 个服务
8. 打印访问地址与账号密码

首次约 10–25 分钟（主要花在 torch / 权重 / npm），之后 30–60 秒。

## 4. 常用参数

| 参数 | 说明 |
|---|---|
| `-CheckOnly` | 只检测环境，不写文件、不启动 |
| `-SkipDeps` | 跳过 Python/权重准备（已装过时用） |
| `-SkipBuild` | 跳过打包与 `npm ci` |
| `-SkipFrontend` | 不启动前端 |
| `-Force` | 重新生成 `.env`、重建 `.venv` |
| `-NoOpen` | 不自动打开浏览器 |
| `-Database <name>` | 改数据库名 |
| `-Port <n>` | 改前端端口 |
| `-MysqlRootPassword <pwd>` | MySQL root 密码（建库/建用户时需要） |

示例：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1 -CheckOnly
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1 -SkipDeps -NoOpen
```

## 5. 数据库说明

| 情况 | 行为 |
|---|---|
| 库已存在且 `hdr` 用户可登录 | 直接复用（不会删数据） |
| 库不存在 | 用 root 建库、建用户并授权 |
| root 密码未知 | 用 `-MysqlRootPassword` 传入，或把密码写进 `scripts/.env` 的 `MYSQL_ADMIN_PASSWORD` |
| 空密码 root | 脚本设置随机密码并写回 `scripts/.env` |

本机复用 `hdr_w2_it_live` 时会保留原有模型、数据集与训练任务；全新机器会自动建空库，Flyway 启动时迁移到最新版本（自带一个基线模型）。

## 6. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 提示缺 JDK/Node/Python | 未安装或不在 PATH | 按提示用 winget 安装，或把路径写进 `scripts/.env` |
| 端口被占用 | 已有一套服务在跑 | 先 `stop-all.ps1`，或换端口 |
| 权重下载失败 | 网络/代理 | 手动把权重放到 `model-service/weights/`，再跑 `-SkipDeps` |
| torch 安装失败 | 网络中断 | 重跑（会续用缓存），或配置 pip 镜像 |
| 数据库连接失败 | 密码不匹配 | 改 `scripts/.env` 的 `DB_PASSWORD`，或用 `-MysqlRootPassword` 让脚本重置 |
| 启动后页面打不开 | 前端未起 | 看 `D:\HDR-runtime\logs\web.err.log` |

日志目录：`D:\HDR-runtime\logs`
环境文件：`scripts/.env`（含密钥，不要提交到 git）
