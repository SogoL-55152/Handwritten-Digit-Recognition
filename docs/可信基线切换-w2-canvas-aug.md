# 可信基线切换：w1-full-3epoch → w2-canvas-aug-3epoch

> 2026-11-07。触发原因与逐例证据见 [画板识别失败诊断](画板识别失败诊断-20261107.md)。
> 本页记录"切换了什么、为什么可信、怎么复现、哪些结论仍然不能宣称"。

## 1. 结论

线上唯一的可信基线已由 `w1-full-3epoch` 换成 `w2-canvas-aug-3epoch`。新基线用**与线上完全一致的几何归一化**生成训练输入，再叠加画板风格增广，从 W1 权重初始化微调 3 轮。

| 指标 | W1 基线 | 新基线 |
|---|---|---|
| MNIST test 直喂模型（1000 张） | 98.9% | 98.9% |
| **真实生产链路下的 MNIST top-1（600 张）** | 93.8% | **99.0%** |
| 真实生产链路下的拒识率（阈值 0.90/0.85） | 14.2% | **5.3%** |
| 同上，被接受样本的正确率 | 98.6% | **100%** |
| 画板风格模拟集（1000 张，与训练增广同源） | 92.1% | 98.2% |

用户真实样本（截图裁切，仅定性）：

| 样本 | 真实 | W1 基线 | 新基线 | 阈值后表现 |
|---|---|---|---|---|
| 4 | 4 | 8（拒识） | **4 (0.999)** | 接受，正确 |
| 9（长尾） | 9 | **7 (0.976)** | **9 (0.802)** | 拒识（分差 0.607） |
| 9（细环） | 9 | 8（拒识） | **9 (0.885)** | 拒识（分差 0.821） |
| 7 | 7 | 1（拒识） | 1 (0.907) | 拒识（分差 0.822） |
| 6 | 6 | 5（拒识） | 5 (0.367) | 拒识 |
| 3（相册照片） | 3 | 2（拒识） | 0 (0.501) | 拒识 |

既有真实截图回归（pilot 的 7/1/0、导入 PNG/JPEG 的 7）：新基线全部识别正确。

## 3. 复现方式

权重目录与 W1 一样被 git 忽略，摘要钉在代码里。复现（`model-service/` 下，需 torch 训练环境）：

```text
python -I train_canvas_aug.py --data-dir data/MNIST/raw --output-dir weights/w2-canvas-aug \
  --init weights/w1-full/checkpoint.pt --epochs 3 --samples 48000 --seed 20261107 --threads 2
```

产出 `checkpoint.pt` 的 SHA-256 与大小必须与清单一致（`f6e1862d…`、1,690,276 字节），否则服务按"可信基线未就绪"返回 503，不会降级。**注意**：不指定 `--threads 2` 或换环境会得到不同权重（本次实测另一份结果为 98.6%/98.0%），这是浮点与线程调度的正常差异；清单钉的是上表命令的产物。

## 4. 拒识阈值没有放宽（有意为之）

实测阈值放宽到 0.70/0.50 时，MNIST 生产链路覆盖率可到 97.7%、保留样本正确率 99.83%，但用户"7 被认成 1"的那一例分数 0.907/分差 0.822 会被**接受为错误答案**。因此维持 0.90/0.85：宁可诚实拒识，也不返回自信的错误数字。

副作用要如实说：上表两个 9 虽然 top-1 已正确，但分数低于阈值，用户仍会看到"无法可靠识别"。

## 5. 仍然不能宣称的

- 画板风格模拟集与训练增广同源，98.2% 偏乐观；**不能当作真实画板准确率**。
- 没有使用任何真实用户样本训练或评测；用户的原图仍未提供（目前只有开发者工具截图裁切）。
- 项目的"真实手写 ≥90%"目标**仍未验证**，需要 W3 自采画板数据。
- 阈值仍是实验性策略，未在真实画板数据上标定；本轮只把**测量口径**改到真实生产链路（此前是在"直喂 28×28"上标定，与线上链路不一致）。
- 相册照片（灰底、低对比）仍会被拒识，属已知限制，不作为承诺。
