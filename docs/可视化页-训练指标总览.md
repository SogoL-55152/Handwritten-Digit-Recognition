# 可视化页：训练指标总览

> 2026-11-18。把原先藏在训练任务行里的指标移到独立页面，便于演示与横向比较。

## 入口

工作台左侧导航 →「可视化」（/visual）。

## 页面结构

`

├──────────────┬─────────────────────────────┤
│ 任务 #20 ✅  │ 任务 #20 · SUCCEEDED         │

│              │ 混淆矩阵 10×10 热力图         │
└──────────────┴─────────────────────────────┘
`

## 与训练任务页的区别

| 项 | 训练任务页 | 可视化页 |
|---|---|---|
| 目的 | 发起/管理任务 | 看指标 |
| 任务选择 | 列表行展开 | 左侧列表，右侧大图 |
| 曲线高度 | 320px | 360px |
| 混淆矩阵 | 窄（520px） | 宽（720px） |
| 汇总指标 | 文字 | 顶部数字卡片 |

## 数据来源

- 任务列表：GET /api/v2/admin/training/tasks?limit=30
- 曲线：metrics.history（每轮损失、三域准确率、耗时）
- 每类与混淆矩阵：metrics.detailed_canvas
- 样本构成：metrics.extra_samples / samples_rendered

没有指标的旧任务会显示“该任务没有逐轮指标”，不报错。

## 参数与结果（2026-11-18 追加）

可视化页新增「参数与结果」区块，把多次训练的**超参数**和**结果**放在一起比：

- **排名条**：按画板模拟准确率排序取前 6 名，最好的一次高亮；每行附样本数、轮数、学习率、是否微调。
- **参数跨度**：样本数 / 轮数 / batch / 学习率 / 照片增广 / 起点各有几种取值——只有 1 种的说明这批任务没在比这个参数。
- **散点图**：X = 样本数，Y = 画板准确率，点大小 = 轮数，蓝色 = 从零训练、紫色 = 微调；悬停显示任务号与数值。

实现：`frontend/src/training/params.js`（`paramRows` / `rankedRows` / `spreadOf`）、
`ParamsChart.vue`（散点，独立持有 echarts 实例，避免 v-for 里字符串 ref 的问题）。
## 平行坐标、两次对比、微调效果（2026-11-18 追加）

- **平行坐标**：一条折线是一次训练，横跨 6 个轴（样本数 / 轮数 / batch / 学习率 / 照片增广 / 准确率），
  用来一眼看出哪次训练在哪个轴上偏离。
- **两次训练对比**：左右各选一个任务，并排看曲线；下方表格列出 8 项参数与结果，**不同的行标黄**。
- **微调效果**：把微调任务与它的起点模型对应起来（按 `initFrom` → `modelVersion` 匹配），
  显示起点准确率、微调后准确率与差值（涨点绿色、跌点红色）。找不到起点的显示“未知”。

实现：`frontend/src/training/params.js`（`fineTunePairs` / `diffRows`）、`ParamsParallel.vue`。
