# 参数可视化（新）：四步向导实现说明

> 2026-11-18。按《参数可视化界面设计方案》实现的**并行新页面**，不改动已有页面（`/visual`、`/training`）。
> 目的：和旧页面并排对比效果。

## 入口

工作台左侧导航 →「**参数可视化**」（`/wizard`）。

```
① 数据集 ─ ② 参数 ─ ③ 监控 ─ ④ 评估
```

## 各步骤做了什么

### ① 数据集

- 选数据集 → 选版本（复用 `/datasets`、`/datasets/{id}/versions` 接口）；
- 训练/验证/测试**比例条**（真实统计，来自版本 stats）；
- 样本缩略图（复用版本样本图片接口，只读展示）；
- 不选版本时按内置 MNIST 60,000 条估算。

### ② 参数（本方案的核心）

**左栏：schema 驱动表单**

`frontend/src/wizard/schema.js` 定义四个分组（数据 / 结构 / 超参 / 运行），前端按
`group → items → widget` 渲染。支持 `dependsOn`：选 SGD 才出现动量，开早停才出现 patience。

| 控件 | 参数 |
|---|---|
| Select | 结构预设、优化器、设备、数据版本 |
| 对数滑块 + 输入框 | 学习率（1e-5 ~ 1e-1） |
| 分段按钮 | batch 16/32/64/128/256 |
| 滑块 | epochs、patience |
| 开关 | 数据增强、早停、混合精度、AMP |

**层编辑器**：卷积层可改 filters / kernel / padding，全连接层可改 units，右侧结构图与参数量实时重算。

**右栏：实时估算（纯前端，输入即反馈）**

| 面板 | 内容 | 算法 |
|---|---|---|
| 结构图 | 每层输出形状 + 该层参数量 | `inferShapes` 逐层推演 |
| 参数量 | 总参数（默认 CNN-2Conv = **421,642**，与线上模型一致） | conv: k²·Cin·Cout+Cout；linear: Cin·Cout+Cout |
| 显存 | 激活 + 参数（含优化器状态），AMP ×0.6 | `estimateMemory` |
| 耗时 | 单步 / 单 epoch / 总耗时 | 以 421k 参数、batch 64 为基准线性插值（CPU 12ms、GPU 1.2ms） |
| 校验 | ✓ / ⚠ / ✗ 三态，警告给可执行建议 | `validateConfig` |
| 配置摘要 | 归一化后的 JSON + `config_hash`（sha256 前 12 位） | `normalizeConfig` + `configHash` |

校验规则（与方案对齐）：

- ✗ 形状推演失败（如 24×24 上做 25×25 卷积）→ 阻止进入下一步；
- ⚠ batch 显存超预算 → 给出"建议 batch ≤ N 或开 AMP"；
- ⚠ Adam 学习率超出 5e-4~1e-3 常用区、SGD 学习率 < 1e-3；
- ⚠ epochs > 20 且未开早停；
- ⚠ 设备为 CPU 时提示耗时约为 GPU 的 10 倍。

### ③ 监控

复用真实训练任务（`/admin/training/tasks`）：逐轮曲线、参数卡片、逐轮明细表（损失/三域准确率/耗时）。
这是**历史回放**，不是实时 WS 推送——方案里的"实时样例墙"需要模型服务在训练中回传样例，暂未实现。

### ④ 评估

同一任务的 MNIST / 画板模拟 / 照片模拟三域准确率 + 每类准确率 + 混淆矩阵（复用 `TrainingMatrix`）。

## 与方案原文的差距（明确没做的）

| 方案要点 | 现状 |
|---|---|
| 后端 `GET /api/train/param-schema` 驱动 | 前端常量 `schema.js` 先落地同一结构，接口可后接 |
| 拖拽层排序（vuedraggable） | 层可改数值，不可拖拽排序 |
| 结构图导出 PNG | 未做（SVG 已在 DOM 里，可后续加） |
| WebSocket 实时指标 + 断线补点 | 未做（用任务历史回放） |
| 训练中实时预测样例墙 | 未做（需要模型服务训练中回传样本） |
| 暂停/继续/停止控制 | 未做（训练任务目前只有创建与状态） |
| 模型对比雷达图 | 旧页 `/visual` 已有排名/散点/平行坐标，新页未重复 |
| 参数模板与草稿 localStorage | 未做 |
