## 4. PC浏览器与实测发现

实际Edge完成注册→个人空间→创建/切换空间→鼠标书写→PNG上传→Java/Python/MySQL→结果展示/记录核对→清空/延迟响应隔离→注销。最终输入“7”预测为7，confidence=0.9950060248374939；记录ID7，本次处理11ms。单样例置信度不是准确率。

本次没有隐去初次失败：

1. **MySQL故障注入方式**：原测试使用触发器，在开启binlog的受限账号下报1419。尝试调整全局设置被拒绝后没有执行或绕过；改为表级CHECK约束阻止新用户会话写入，并断言MySQL3819错误及完整回滚。驱动将其归为UncategorizedSQLException，修正测试异常类别后15项全通过。`log_bin_trust_function_creators`始终保持0。
2. **缺少站点图标**：浏览器Console出现favicon404；补上SVG图标并重跑。
3. **识别结果延迟消失**：自动化初版看见结果即通过，但查看截图发现结果后来被清空。ResizeObserver在图片像素未变化时仍触发revision失效；增加相同位图尺寸早返回及单测，并加入布局稳定/截图后的结果持久性断言。修复后10项浏览器检查通过，已实际查看最终截图。
