# SVHN：数据集可用性与正确率评测

> 2026-11-18。纠正前一版判断：`train.tar.gz` / `test.tar.gz` 里**有标签**，它们是 SVHN
> （Street View House Numbers）。之前只看前 25 个条目、只看到 PNG，误判为"无标签"。

## 1. 这是什么

| 文件 | 内容 | 图片数 | 标签 |
|---|---|---|---|
| `train.tar.gz` | `train/*.png` + `train/digitStruct.mat` | 33402 | 有（含框） |
| `test.tar.gz` | `test/*.png` + `test/digitStruct.mat` | 13068 | 有（含框） |

`digitStruct.mat` 是 MATLAB 7.3（HDF5）。每张图给出若干数字框（left/top/width/height）
与标签（label=10 表示数字 0）。位数分布：

| 位数 | 训练集 | 测试集 |
|---|---|---|
| 1 位 | 5137 | 2483 |
| 2 位 | 18130 | 8356 |
| 3 位 | 8691 | 2081 |
| 4 位 | 1434 | 146 |
| 5+ 位 | 10 | 2 |

所以**它能用来做真正的正确率评测**，也能用来训练检测器与微调模型。

## 2. 评测工具

`model-service/tools/svhn_eval.py`：读取 `digitStruct.mat`，按三种口径跑同一批图：

- `baseline`：整图直接多位识别（线上默认）
- `detect`：先 `digit_detect` 找数字区再切分（`detect=1`）
- `oracle`：用数据集给的框裁剪（**检测上限**，衡量"检测完美时能到多少"）

```powershell
cd model-service
python -I tools/svhn_eval.py --images D:/Temp/hdr-scene/test `
  --labels D:/Temp/hdr-svhn/test/digitStruct.mat --limit 13068 --out D:/Temp/svhn-report-full.json
```

## 3. 全量结果（13068 张，模型 `w4-task-8-a1`，maxDigits=3）

| 口径 | 接受率 | 接受内完全正确 | 全体完全正确 | 接受内逐位正确 |
|---|---|---|---|---|
| baseline | 21.25% | 14.37% | 3.05% | 29.81% |
| detect | **36.06%** | 11.74% | **4.23%** | 27.71% |
| oracle（给定框） | 37.61% | **30.91%** | **11.62%** | **53.46%** |

按位数（全体完全正确率）：

| 位数 | baseline | detect | oracle |
|---|---|---|---|
| 1 位（2483 张） | 8.8% | 12.2% | **35.1%** |
| 2 位（8356 张） | 1.9% | 2.7% | 7.3% |
| 3 位（2081 张） | 1.1% | 1.4% | 4.1% |

耗时：三种口径各跑一遍全量约 206 秒（进程内推理，不走 HTTP）。

## 4. 怎么解读

1. **检测确实有效**：接受率 21.25% → 36.06%，`DIGIT_LIMIT` 从 2941 降到 405。
2. **但检测不是全部**：接受内完全正确率反而略降（14.37% → 11.74%）——检测把更难的样本也捞了上来。
3. **真正的瓶颈是模型域差异**：即使给标准框（oracle），2 位数字只有 7.3% 完全正确、
   逐位才 53%。这是一个**手写数字模型**去认**印刷体街景数字**，字体、模糊、透视全都不在训练分布里。

## 5. 结论：能用，而且用法不止一种

| 用法 | 可行性 | 说明 |
|---|---|---|
| **正确率评测** | ✅ 已做 | 13068 张带标签，可当"真实场景"基准 |
| **检测器训练** | ✅ 可以 | 33402 张带框，可训练小检测器替代启发式定位 |
| **模型微调** | ✅ 最值得做 | 33402 张带标签，微调后预计大幅提升拍照场景准确率 |
| 提升手写准确率 | ❌ 不适用 | 印刷体 ≠ 手写，别指望它提升画板数字 |

## 6. 下一步建议

如果目标是"**拍照导入的准确率**"，按这个顺序做：

1. 用 `train.tar.gz` 的框把数字裁好，微调现有模型（1–2 轮，保持手写样本混训）；
2. 微调后用本工具在测试集上对比 `exactMatchOverall` 与 `digitAccuracy`；
3. 同时跑手写评测（现有 239 项单测 + 画板样本），确认手写没有回退；
4. 若微调有效，把"拍照"链路的默认模型切到新版本。
## 7. SVHN 微调（2026-11-18 实跑）

用 `train.tar.gz` 的**逐字框**裁出单字，按线上同一个 `canvas_input` 归一化后微调现有模型：

| 项 | 值 |
|---|---|
| 训练样本 | 60,000 个 SVHN 单字（来自 33,402 张图） |
| 混训样本 | 24,000 MNIST（照片增广 0.5），防止只学印刷体 |
| 超参 | 2 轮，batch 128，lr 1e-4，Adam |
| 耗时 | 约 20 秒（CPU） |
| 产物 | `weights/w4-svhn-ft/checkpoint.pt`，登记为 `w4-svhn-ft-1`（INACTIVE） |

### 逐字准确率（SVHN 测试集 4,000 个单字 + MNIST 2,000）

| 模型 | SVHN 单字 | MNIST |
|---|---|---|
| `w4-task-8-a1`（原） | 52.80% | 89.80% |
| `w4-svhn-ft-1`（微调） | **70.65%** | 89.30% |

### 端到端（SVHN 测试集 2,000 张，oracle 用给定框）

| 口径 | 原模型 | 微调后 |
|---|---|---|
| baseline 接受率 | 21.35% | 11.40% |
| baseline 接受内完全正确 | 11.71% | **24.12%** |
| oracle 接受率 | 37.60% | 24.50% |
| oracle 接受内完全正确 | 29.12% | **57.76%** |

微调后的模型**更谨慎**：准确率翻倍但接受率下降。把判据阈值从 0.90 往下调可以在同一覆盖下拿到更高精度：

| 阈值 | 原模型 覆盖/精度 | 微调 覆盖/精度 |
|---|---|---|
| 0.90 | 32.7% / 29.1% | 20.9% / 58.6% |
| 0.80 | 42.9% / 26.4% | 27.6% / 51.4% |
| 0.70 | 49.1% / 24.4% | 33.1% / **47.5%** |
| 0.50 | 63.3% / 21.6% | 43.9% / 39.3% |

**关键结论**：在覆盖 33% 这个相同水平上，精度从 29.1% 提到 47.5%（+63% 相对提升）。

### 怎么用这个模型

- 它已登记进**模型管理**：模型页显示来源「微调」、起点 `w4-task-8-a1`、准确率 70.65% · SVHN 单字 4000 个；状态 `INACTIVE`，画板默认仍然用 `w4-task-8-a1`；
- 手写（MNIST 模拟）掉了 0.5 个点，画板是产品主线，是否切换要按真实手写样本再确认；
- 如果只为"拍照导入"换模型，建议配合阈值 0.70 使用，否则接受率会明显下降。

### 复现

```powershell
cd model-service
python -I tools/svhn_finetune.py --epochs 2 --digits 60000 --mnist 24000 --lr 0.0001
# 产物在 weights/w4-svhn-ft/checkpoint.pt，脚本会打印 sha256/sizeBytes 与前后对比
```
### 7.1 单段校验版（w4-svhn-ft-2，2026-11-18）

按框裁字时如果加了边距，可能把相邻数字一起裁进来（实测 8% 边距下 **约 14% 的裁图出现 2–3 段前景**），
这些样本的标签是错的。给 `crop_digits` 加了校验：

- 裁完跑一次 `segments_of`，段数必须 = 1；
- 不满足就缩到 0 边距重裁；仍 >1 段则跳过并计数。

| 项 | 结果 |
|---|---|
| 训练样本 | 60,000 个单字（跳过多段样本）+ 24,000 MNIST |
| 跳过 | 多段样本按比例剔除（日志里有计数） |
| 超参 | 2 轮、batch 128、lr 1e-4（与 ft-1 相同，便于对比） |

| 模型 | SVHN 单字 | MNIST | oracle 接受内正确 | baseline 接受内正确 |
|---|---|---|---|---|
| `w4-task-8-a1`（原） | 52.80% | 89.80% | 29.12% | 11.71% |
| `w4-svhn-ft-1`（未校验） | 70.65% | 89.30% | 57.76% | 24.12% |
| **`w4-svhn-ft-2`（单段校验）** | **73.68%** | 89.25% | **60.21%** | **25.81%** |

判读：清洗训练样本后，单字准确率 +3.0 个点；端到端"答对的数量"基本不变，但**误答更少**（precision 提升）。

复现：

```powershell
cd model-service
python -I tools/svhn_finetune.py --epochs 2 --digits 60000 --mnist 24000 --lr 0.0001
```
