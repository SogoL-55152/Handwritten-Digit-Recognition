# 模型权重与产物管理

> 结论：**权重不进 git**。仓库里只有 `.gitkeep`，首次克隆后用脚本从 GitHub Release 下载生效基线。

## 1. 为什么不在仓库里

| 原因 | 数据 |
|---|---|
| 体积 | `model-service/weights/` 现有 111 个文件、**114.5 MB** |
| 单个模型 | 约 1.65 MB（CNN 2Conv，参数 421,642） |
| 产物属性 | 训练任务的输出，随每次训练增长 |
| GitHub 限制 | 单文件 100 MB；仓库历史会永久保留每个版本 |

现有 `.gitignore`：

```
model-service/weights/*
!model-service/weights/.gitkeep
```

## 2. 分发方式：GitHub Release（只需基线）

- Release 标签：`weights-v1`
- 附件：`hdr-weights-baseline-v1.zip`（约 1.5 MB）
- 内容：
  - `w4-train/8/checkpoint.pt`（生效模型 `w4-task-8-a1`，sha256 与 registry 一致）
  - `registry.json`（**只含这一个模型**，避免指向缺失文件）
  - `MANIFEST.json`（版本、文件名、sha256、大小，供脚本校验）

仓库里新增脚本，按需下载并校验，不参与构建。

## 3. 首次拉取（新同事 / 新机器）

```powershell
# Windows
powershell -ExecutionPolicy Bypass -File scripts/fetch-weights.ps1
```

```bash
# Linux / macOS（需要 unzip 与 python3）
bash scripts/fetch-weights.sh
```

脚本行为：

1. 下载 zip（或 `-ZipPath/--zip` 指定本地文件）
2. 读 `MANIFEST.json`，逐个文件解压到 `model-service/weights/`
3. 对每个文件做 **sha256 校验**，不一致立即失败
4. 若本地没有 `registry.json` 才写入；已存在则跳过（保护本机已有训练产物），
   需要覆盖时加 `-ForceRegistry` / `--force-registry`

离线安装：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/fetch-weights.ps1 -ZipPath dist/hdr-weights-baseline-v1.zip
```

## 4. 发布新基线（维护者）

1. 在本机训练出新的生效模型，确认 `model-service/weights/registry.json` 里对应条目 sha256 正确
2. 重新打包（会把当前生效模型写进 zip）：

```bash
python scripts/build-weights-baseline.py
# 产物：dist/hdr-weights-baseline-v1.zip
```

3. 在 GitHub 打 Release：
   - Tag：`weights-v2`（递增）
   - 附件上传 `dist/hdr-weights-baseline-v1.zip`
4. 更新两个 fetch 脚本里的默认 URL 与 zip 名，提交

> 之所以不把 26 个训练产物一起发：它们只对训练这台机器有意义，
> 新环境需要的是「能跑起来」的基线，其余靠重新训练获得。

## 5. 部署机上的处理

- 部署（Compose/Linux）时把 `weights/` 作为数据卷挂载，不随镜像发布
- 首次启动前执行一次 `fetch-weights`，或在镜像构建时 `RUN bash scripts/fetch-weights.sh`
- 训练产物继续写 `weights/`，由 `registry.json` 管理，不进 git

## 6. 排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 模型服务启动报找不到模型 | 没跑 fetch 脚本 | 执行脚本后重启模型服务 |
| `校验失败：w4-train/8/checkpoint.pt` | 下载不完整或文件被改 | 删除后重新下载 |
| 已存在 `registry.json` 被跳过 | 保护本机产物 | 需要覆盖时加 `-ForceRegistry` |
| `找不到可用的 python`（sh） | Windows 上 `python3` 是商店占位符 | 用 `HDR_PYTHON=/path/to/python` 指定 |
| 下载 404 | Release 未发布或 tag 不匹配 | 检查 Release 附件名与脚本里的 URL |
