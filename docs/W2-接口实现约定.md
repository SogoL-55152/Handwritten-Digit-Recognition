# W2 接口实现约定（本地开发基线）

> 依据 Wiki v2/cd9bbe7；2026-11-02。此页先冻结联调合同，实际完成与测试状态另见 W2 交付记录。不代表所有接口已完成。

## 通用

- Java 根地址 `/api/v2`；成功 `{code:0,message:"ok",data:...}`，失败 HTTP 4xx/5xx 且 `{code:<status>,message,data:{category?,retryAfterSeconds?,requestId?}}`，代理错误可能非 JSON。
- 所有数据库 ID 返回字符串；时间 UTC ISO-8601。数字范围不能使用 NaN/Infinity。
- 账号平台角色 `USER|SUPER_ADMIN`，空间角色 `OWNER|ADMIN|MEMBER`，两者分开。普通用户可识别；运营不自动拥有空间。
- Token 缓存使用新 v2 key，旧 W1 token 不能被新入口信任。401 清当前请求所属会话；403/404 不无条件退出。
- 业务请求按用户当前身份/会话+当前空间授权；非成员/跨空间返回404，成员缺操作权限403。

## 身份/空间

`POST /auth/register` JSON `{username,password,nickname?}`，username 3–32 非空白，password 6–32 非空白，nickname 最长64；201，自动创建会话。
`POST /auth/login` JSON `{username,password}`；200。
二者 `data={token,user:{id,username,nickname,platformRole},defaultWorkspaceId}`。
`GET /auth/me`：`data={user:{id,username,nickname,platformRole},defaultWorkspaceId}`。
`POST /auth/logout`：撤销当前会话，data=null。

`GET /workspaces` 返回数组 `[{id,name,role,status,defaultModelId}]`（当前有效成员的空间）。
`POST /workspaces` JSON `{name}`（非空、最多64），201返回同样 Workspace，创建者 OWNER；每账号最多创建3个（包含个人空间）。
`GET /workspaces/{wid}` 返回 Workspace。工作空间切换无需服务端 active 全局变量，以每次 URL 为准。

## 公共只读资产

空间资源根路径 `/workspaces/{wid}`。
`GET .../models` 返回模型数组；`GET .../models/{id}` 和 `GET .../default-model` 返回模型：
`{id,name,version,scope,workspaceId,externalId,accuracy,accuracyDataset,preprocessVersion,description}`。
W2 基线 externalId=`mnist-cnn-w1`，version=`w2-canvas-aug-3epoch`，preprocessVersion=`canvas-mnist-v1`。accuracy 字段=.982，accuracyDataset 明确标注为 `canvas-simulated synthetic (not real user data)`；MNIST test 为 .989。公共 scope=`PUBLIC`；私有测试夹具 scope=`WORKSPACE`，不可跨空间访问。模型元数据存在不代表推理已就绪。

`GET .../datasets` 返回数组；`GET .../datasets/{id}` 返回：
`{id,name,version,scope,workspaceId,trainSamples,testSamples,description}`。MNIST公共元数据60000/10000，version=`mnist-original`。
无资源上传、删除、默认切换接口。

## 识别

`POST .../recognitions` multipart：唯一 `image` PNG/JPEG，`source=WEB|MINIPROGRAM`；请求头 `Idempotency-Key: <UUID>`。
文件最大5MiB，请求6MiB，最大边长2048、总像素4194304，拒绝动画/损坏/空白。只针对画板输入。
成功 data：`{recognitionId,requestId,digit,confidence,modelId,modelVersion,preprocessVersion,source,processingMs,createdAt}`。
`requestId` 为 Idempotency-Key 的小写规范形式（客户端应直接生成小写UUID）；digit整数0..9、confidence有限0..1。
`GET .../recognitions/{id}` 返回同样结果，仅当前空间本人可见。
同键同图/source成功后返回原结果；处理中409 category=IN_PROGRESS；内容不同409 category=IDEMPOTENCY_CONFLICT；已失败409 category=REQUEST_FAILED。不自动重发POST，用户明确新操作使用新UUID。
结果、错误、loading状态都需会话/空间/画板revision三重过期保护。

## 用量/运营

`GET .../usage` data：
`{workspaceId,scope:"SELF",totalRequests,successfulRequests,failedRequests,limits:{maxWorkspaces:3,maxMembers:5,imageMaxBytes:5242880,recognitionPerMinute:60,dailyRecognitionLimit:1000,dailyQuotaEnforced:false,remainingDaily:null,trainingAvailable:false,storageMeteringAvailable:false}}`。
总数是该用户在该空间已有识别记录统计，不是已启用的日配额账本。
`GET /platform/quotas` 限SUPER_ADMIN，返回 `limits` 同上述预算配置并加 `source:"configuration",restartRequired:true`；只读，不提供编辑。
`GET /platform/health-summary` 限SUPER_ADMIN：`{checkedAt,services:[{name,status,detail}]}`，状态 `UP|DOWN|NOT_CONFIGURED`。探测MySQL、模型readiness，Redis/训练为NOT_CONFIGURED，不输出密钥/路径。
空间权限失效后各资源仍由后端实时拒绝。

## Python 内部服务

内部认证 header `X-HDR-Internal-Token`，来自环境 `MODEL_INTERNAL_TOKEN`，未配置不得开放预测。
`POST /internal/v2/predict` multipart image，字符串字段 workspaceId/requestId/modelId/modelVersion/preprocessVersion；modelId为外部固定标识`mnist-cnn-w1`。
回包 envelope 同Java；data `{requestId,digit,confidence,modelId,modelVersion,preprocessVersion,processingMs}`。
`GET /internal/v2/ready` 同认证，200 data `{status:"UP",modelId,modelVersion,preprocessVersion,sha256}`；缺权重/摘要不符503，不能随机权重兜底。
full checkpoint SHA256 `f6e1862dae34ff13b7cab29ebb61b22b49fe0041cb9e347289d50d62695deaed`，size1690276；服务端配置路径由管理员控制，不能从请求传入。
Java连接超时2秒/读取10秒，客户端超时略长；无POST自动重试，外部仅Java入口可访问。

## W2 训练页面边界

仅参数校验原型：modelName非空最多64、固定DigitCNN、epoch1..5、batchSize32/64/128、有限learningRate(0,0.1]、seed整数0..4294967295。不创建任务、不开worker、不生成曲线，按钮标“校验参数”。训练数据选项真实集成和在线训练分别在W3/W4。
指标合同仅定义：taskId/attempt/seq/epoch/totalEpochs/trainLoss/valLoss/valAccuracy/elapsedMs/recordedAt；缺失指标不造假0，W1 test指标不改为validation。
