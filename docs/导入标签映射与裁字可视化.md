# 导入标签映射与多位数裁字可视化

> 对应交接文档 P1-9：「标签映射 UI（CSV 上传时列名映射、多位数裁字可视化）——现在靠自动识别，失败只能重来」
> 完成日期：2026-11-25

---

## 1. 改动前的问题

1. **CSV 列名靠猜**：只有表头命中 `file/name/image/label/digit/class/y` 这些英文关键字才认，
   中文表头（`文件名,标签`）或业务自己的列名（`colA,colB`）一律猜不中。
2. **猜不中不报错**：`readCsv` 找不到列就返回空 map，于是每张图都被记成"csv 里没有这个文件"、
   预览显示 **可导入 0 张**，用户看不到"是列没对上"，只能反复换目录重来。
3. **多位数图只给一句话**：自检发现含多个数字时只提示"建议先裁成单字"，不告诉你**会怎么切**；
   而且自检用的是 `maxDigits=2`，**3 位以上的图直接 422**，既不算多位数也不给提示（静默漏检）。

## 2. 现在的行为

### 2.1 CSV 列映射（手动 + 自动）

预览响应新增 `csv` 字段：

```json
"csv": {
  "fileName": "labels.csv",
  "columns": ["colA", "colB"],
  "rows": 10,
  "fileColumn": null,
  "labelColumn": null,
  "matched": false,
  "unmatched": 10
}
```

- 前端在预览里渲染两个下拉（文件列 / 标签列）+「用这个映射重新试运行」+「恢复自动识别」；
- `POST .../import-wizard/preview` 与 `.../import-wizard` 都接受
  `{directory, fileColumn, labelColumn}`，列可以写**列名**或**1 起的序号**；
- **显式给了列名却找不到时不回落猜测**（返回 -1 → `matched=false`）。否则用户选了某列却被静默换掉，比报错更难查；
- 提交时若 CSV 列仍未匹配，返回 `400 CSV_COLUMNS_UNMAPPED` 和"请手动选择这两列"，
  而不是"导入 0 张"。

自动识别规则（未显式指定时）：

1. 先**精确匹配**表头：`file/filename/name/image/path/文件名/文件/图片名/图片/图像/路径`；
   标签列：`label/digit/class/y/标签/数字/类别/标注`；
2. 再按**英文关键字包含**匹配（`image_path`、`label_v2` 这类）；
3. 中文**不做包含匹配**——否则「标签路径」会被当成文件列。

CSV 行解析同时补齐：支持引号包裹字段、字段内逗号、`""` 转义（原来直接 `split(",")`）。

### 2.2 多位数裁字示意

自检命中多位数时，预览额外返回最多 3 条 `cutSamples`：

```json
"cutSamples": [{
  "sample": "multi_5.png",
  "thumbnail": "data:image/jpeg;base64,...",   // 96px 宽缩略图
  "text": "128",
  "digits": [
    {"digit": 1, "confidence": 0.99, "from": 0.0, "to": 0.09},
    {"digit": 2, "confidence": 0.98, "from": 0.38, "to": 0.61},
    {"digit": 8, "confidence": 0.97, "from": 0.76, "to": 1.0}
  ]
}]
```

前端画成一条**按相对宽度分段的比例条**，每段标注数字与置信度，旁边是缩略图。

> `from/to` 是"检测到的笔画整体跨度"内的相对位置，坐标系是模型服务预处理后的画布，
> **不是原图坐标**，所以只画比例条、不往原图上叠框——叠框会给人"框就长这样"的错误印象。
> 响应里也写了这句话。

自检的 `maxDigits` 从 2 改成 **4**：只要 2 位就会被拒识入库，所以 3–4 位也必须被检出。

## 4. 已知局限

1. **只支持单表单条 CSV**（与导入向导"一个目录一份标签表"的模型一致）；多表或多 sheet 不支持。
2. **标签只认单个 0–9**：CSV 里写 `12` 这种多位数标签会被跳过并计入 `unmatched`；
   多位数样本目前只能来自画板手输整串（`label_text`），不在导入向导范围内。
3. **切分示意只取前 3 张**、且只检查前 4 张（自检抽样上限），不是全量扫描。
4. **缩略图是服务端渲染后内联的 base64**：单张 ≤ 96px，预览响应增加几 KB；没有做图片存储或缓存。
5. **中文列名只做精确匹配**：`文件名称`、`图片文件` 这类仍需手动选择（有意为之，避免误匹配）。
