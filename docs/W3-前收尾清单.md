## 3. 误识别复现（9→7、乱画漏拒）

工具、可信权重、诊断字段都已就绪；整条链路本轮已用合成样例实测跑通（链路可用性验证，不是用户证据）。

1. 新建样例目录（不要放进仓库），把**原图**复制进去（画板导出的 PNG 或相册原图，不要截图二次压缩）。
2. 在该目录写 `manifest.json`：

```json
{"samples":[
  {"id":"u9-1","file":"u9-1.png","label":9,"origin":"actual-user-board","writerId":"w1","captureSessionId":"s1","consent":true},
  {"id":"u7-1","file":"u7-1.png","label":7,"origin":"actual-user-board","writerId":"w1","captureSessionId":"s1","consent":true},
  {"id":"scribble-1","file":"scribble-1.png","label":"non-digit","origin":"actual-user-board","writerId":"w1","captureSessionId":"s1","consent":true}
]}
```

`label` 只能是 0–9 或 `"non-digit"` / `"ambiguous"`；`origin` 用 `actual-user-board`（小程序画板原始导出）、`actual-user-album`（相册导入）或 `synthetic`；`consent` 必须为 `true` 且确实获得当事人同意。

3. 运行（`--output` 必须是**不存在**的新目录）：

```text
python -I model-service/evaluate_samples.py --manifest <样例目录>/manifest.json ^
  --checkpoint <仓库>/model-service/weights/w1-full/checkpoint.pt ^
  --output <新的输出目录> --save-preprocessed
```

4. 看 `report.json` 中每一例：

| 字段 | 说明 |
|---|---|
| `baseline_digit` | 不改拒识策略时模型的答案（即用户看到的错误数字来源） |
| `top_two` | 前两名类别与分数，看 9 是否只是第二名 |
| `margin` | 第一名减第二名，`<0.85` 会被拒识 |
| `quality` | `foregroundPixels` / `bboxFill` / `significantRegions` |
| `rejection_reason` | 非空说明输入被判无效，用户本应看到提示而不是数字 |
| `preprocessed/000N.png` | 真正送进模型的 28×28 输入，可与 MNIST 手写形态直接对比 |

判读原则：

- **`top_two` 里 9 排第二且分数接近** → 模型边界混淆，属于数据问题，靠调阈值解决不了，应进入自采数据/微调评估。
- **`bboxFill`、`foregroundPixels` 明显异常，或 `preprocessed` 里的 9 环被压扁、断开** → 预处理（裁剪/缩放）把结构吃掉了，属于代码问题，可定点修。
- **`rejection_reason` 非空** → 用户本应看到拒识提示，若他看到了数字，说明提示链路有问题。

没有原图就无法定点修复，这一点已在 [通用拒识：本地验证与已知局限](通用拒识-验证与局限.md) 登记；不要用"已知 99.10% MNIST"来回答用户那张 9。

## 5. 本轮顺手记下的两条契约细节

- 识别上传的 `source` **必须是 multipart 表单字段**（与小程序 `formData:{source:'MINIPROGRAM'}` 一致），且请求不能带 query string；带 query 会被服务端 400 拒绝，附带的其它字段同样拒绝。
- 本机用脚本拉起 Python 服务时，子进程环境必须**叠加在父环境之上**：整体替换会丢掉 `SystemRoot`，Python 的 Winsock 初始化随即失败（`WinError 10106`）。`scripts/local-demo.py` 已经是叠加写法，自写脚本要照做。
