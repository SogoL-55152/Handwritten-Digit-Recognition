## Wiki 与仓库文档

Wiki 是团队文档协作入口；本目录保存版本快照，两者不会自动同步。本轮发布先核对 Wiki 最新历史，保留了用户删除“每周会议记录”的修改。以后同步仍应先读取线上最新内容，合并组员修改后发布，不能直接用旧快照覆盖。OpenAPI、代码和轻量指标保留在代码仓库，由 Wiki 链接引用。

本次更新 Wiki 不代填成员确认，也不代表完成全部 DoD；数据库真实落库、浏览器与小程序真机验证的状态见交付记录。
