# 数据集：导入样本与跨版本合并

> 2026-11-18。对应两个需求：① 把外部图片导入数据集；② 从已有版本挑样本合并成新版本/新数据集。

## 1. 数据模型（V18）

`t_collected_sample` 新增两列：

| 列 | 作用 |
|---|---|
| `source_dataset_id` | 这批图片是被导入到哪个数据集时进来的 |
| `imported_at` | 导入时间 |

导入的样本 `sample_kind='IMPORTED'`、`consent=1`（导入即视为同意），和识别页采集的样本躺在同一个池子里——
所以“建版本”的规则不变：**先导入，再建版本，训练才用得到**。

## 2. 导入接口

```
POST /api/v2/workspaces/{wid}/datasets/{datasetId}/import
  multipart: label=0..9, files=@a.png, @b.png, ...
```

- 单次最多 200 个文件，单文件沿用 5 MB 限制；
- 按 `(workspace_id, creator_id, 图片sha256)` 去重，重复的计入 `duplicates` 不报错；
- 返回 `{imported, duplicates, failed, total}`。

**页面**：`/datasets` → 选中数据集 → 「导入样本」面板：选标签、多选图片、点导入，显示
`成功 N · 重复 M · 失败 K`。

## 3. 建版本支持「样本来源」

```
POST /api/v2/workspaces/{wid}/datasets/{id}/versions
{
  "version": "v1",
  "splitRule": "RANDOM",
  "valPercent": 20,
  "testPercent": 20,
  "sources": [
    { "versionId": 3, "limit": 30 },
    { "versionId": 2, "limit": 10 }
  ]
}
```

- `sources` 为空 → 沿用旧行为（整个采集池，可加 `label` / `kind` 过滤）；
- `sources` 非空 → 从这些版本的 `t_v2_dataset_sample` 复制样本行到新版本；
- **跨来源按 `sample_id` 去重**（同一张图出现在两个版本里只算一次）；
- 每个来源可单独限制条数，并可用 `labels: [0,1,2]` 只取某几类；
- 版本仍然重新划分 train/val/test，统计照常更新。

**页面**：建版本面板下方新增「样本来源（可选）」：勾选版本、填条数；不勾选就是原来的整池行为。

另加 `GET /api/v2/workspaces/{wid}/dataset-versions?limit=50` 跨数据集列出可用版本（供上面的勾选）。

## 4. 实测（2026-11-18）

用 SVHN 测试集里裁出的 30 个真实数字（0–9 各 3 张）跑了一遍：

| 步骤 | 结果 |
|---|---|
| 导入 30 张 | 成功 30 · 重复 0 · 失败 0 |
| 重复导入同一批 | 成功 0 · **重复 30** |
| 按 `kind=IMPORTED` 建 v1 | 30 条（只含导入样本，没混入已有的 48 条） |
| 合并建版本：v1(30) + 数据集3 v1 取 10 条 | **40 条**，去重正确 |
| 合并后划分 | TRAIN 24 / VAL 8 / TEST 8 |

8 项断言全部通过。

## 5. 现状限制

- 导入只支持**单字标签**（0–9），多位数字串暂不支持；
- 导入不校验图片内容是否真的是数字（标签由用户给），脏数据会进池子；
- 合并只按 `sample_id` 去重，不做“内容近似”去重；
- 版本被训练任务引用后仍**可以删除**（保护还没做），删了会让历史任务指向不存在的版本。
## 6. 方式 A：SVHN 导入脚本（`tools/svhn_import.py`）

`train.tar.gz` / `test.tar.gz` 是 SVHN：一张图 1–6 个数字 + `digitStruct.mat` 里的框。
不能直接导入，脚本按框裁成单字、过"单段校验"后分批调导入接口。

```powershell
cd model-service

# 先干跑，只看能裁多少、跳过多少
python -I tools/svhn_import.py --images D:/Temp/hdr-svhn/train `
  --labels D:/Temp/hdr-svhn/train/digitStruct.mat --per-label 50 --dry-run

# 真导入（自动建数据集）
python -I tools/svhn_import.py --archive D:/noname/train.tar.gz `
  --labels D:/Temp/hdr-svhn/train/digitStruct.mat --per-label 500 `
  --dataset-name "SVHN-单字-5000"
```

| 参数 | 说明 |
|---|---|
| `--archive` / `--images` | 直接读 tar.gz（不解压到磁盘）或读已解压目录，二选一 |
| `--labels` | `digitStruct.mat` |
| `--per-label` | 每类最多导入多少个（控制规模） |
| `--batch` | 每批上传张数，默认 20（避开 6MB 请求上限） |
| `--dataset-name` / `--dataset-id` | 自动建数据集，或导入到已有数据集 |
| `--dry-run` | 只裁剪 + 校验，不写库 |
| `--limit-images` | 只扫描前 N 张图（调试用） |

**单段校验**（脚本的核心）：裁完先跑 `segments_of`，段数必须 = 1；否则缩到 0 边距重裁，
仍 >1 段就跳过并计入 `multiSegment`。这样避免了"把邻居数字裁进来、标签还是错的"。

### 实测（2026-11-18）

```
每类 50 个，扫描 400 张图：
裁出 500 个单字，跳过：多段 23、过小 41
导入：成功 500 · 重复 0 · 失败 0，耗时 1.8s
重跑同一批：成功 0 · 重复 500     ← sha256 去重生效
```

导入后在该数据集上建版本：606 条（含之前另一批导入样本），划分 TRAIN 365 / VAL 123 / TEST 118。

### 限制

- 建版本默认用**整个采集池**，不区分"哪一批导入的"；只想用这批 SVHN 时用 `kind=IMPORTED`
  或建版本时的「样本来源」勾选；
- 只能按单字导入；多位数图片需要先裁成单字；
- 类别不均衡是 SVHN 本身的分布（1 最多、9 最少），`--per-label` 会按类封顶拉平。
## 7. 「导入数据集」按钮（按文件夹批量导入）

`/datasets` 顶部新增「导入数据集」：先选中数据集，再选一个**按 0–9 分文件夹**的目录，
浏览器会把整个目录读进来，按子目录名当标签自动分批导入。

```
我的数据/
├── 0/  img001.png …
├── 1/  img001.png …
├── …
└── 9/  img010.png
```

- 只认**第一层目录名**为 0–9；更深的层级会被忽略（`3/sub/a.png` 仍算标签 3）；
- 非图片文件自动跳过并计数；不在 0–9 目录下的图片记为“无标签目录”；
- 每批 20 张（服务端单请求 6 MB 上限），全部在浏览器里分批，**支持几百到几千张**；
- 导入过程显示「标签 3（2/10）· 第 1/4 批」，完成后显示成功/重复/失败；
- 重复判定仍然按 sha256：同一张图换目录、换文件名都算重复。

### 实测

- 20 张一批：`200`，`duplicates 20`（这批之前导过，去重生效）；
- 前端单测覆盖：目录标签解析、非图片过滤、分批、汇总、进度文本。

### 与「导入样本」面板的分工

| 入口 | 适合 |
|---|---|
| **导入数据集**（顶部按钮） | 已经按 0–9 分好目录，几百到几千张 |
| **导入样本**（数据集面板内） | 少量图片、只有一个标签；或标签不在目录名里 |

### 限制

- 浏览器支持 `webkitdirectory`（Chrome / Edge / 新版 Firefox），Safari 旧版可能不支持；
- 标签必须体现在目录名；如果标签在 CSV 或文件名里，需要用脚本（见第 6 节的思路）。
## 8. 「导入标注数据集」按钮（按钮触发脚本）

`/datasets` 顶部新增「导入标注数据集」（原名「导入 SVHN 包」）：选中数据集 → 填解压目录（含 `digitStruct.mat`）→ 填每类数量 → 开始导入。
接口路径仍叫 `import-svhn`（按 digitStruct.mat 的框裁字），因为目前只认这一种标注格式。
后端会拉起 `model-service/tools/svhn_import.py`，把输出汇总回给页面。

```
POST /api/v2/workspaces/{wid}/datasets/{id}/import-svhn
{ "directory": "C:/.../train/train", "perLabel": 500 }
→ { exitCode, seconds, summary: {imported,duplicates,failed,skipped}, log }
```

### 配置（`application.yml`）

| 配置 | 默认值 | 说明 |
|---|---|---|
| `hdr.import.python` | `D:/Temp/hdr-w4-venv/Scripts/python.exe` | 跑脚本的 Python |
| `hdr.import.script` | `model-service/tools/svhn_import.py` | 脚本路径 |
| `hdr.import.root` | `.`（工作目录） | **只允许导入这个根目录下的路径** |
| `hdr.import.timeout-seconds` | `900` | 超时后强制结束 |

也可以用环境变量覆盖：`HDR_IMPORT_PYTHON` / `HDR_IMPORT_SCRIPT` / `HDR_IMPORT_ROOT` / `HDR_IMPORT_TIMEOUT_SECONDS`。

### 实测

```
按钮 → 目录 train/train，每类 56：
状态 200 · exit 0 · 耗时 36.5s
summary: imported 10 · duplicates 550 · failed 0
skipped: multiSegment 24、tooSmall 45
```

（550 是之前导过的，去重生效；这次新增 10 个。）

### 边界

- 目录必须在 `hdr.import.root` 之下，否则 400 `PATH_NOT_ALLOWED`；
- 目录里必须有 `digitStruct.mat`，否则 400 `LABELS_NOT_FOUND`；
- 每类数量 1..20000；脚本同步执行，规模大时页面会等待（有 900 秒超时）；
- 这是本地一体化实现（后端 spawn Python）。**生产环境应改成队列任务**，避免占用 Web 线程。
## 9. 导入归属与「样本范围」（2026-11-18 补）

之前导入只写进采集池，建版本默认用整池 → 导入到 A 数据集的图片会出现在 B 数据集的版本里。
现在补了归属与范围：

### 导入归属

每条导入样本都记 `source_dataset_id`（导入时选中的数据集）。物理文件仍放在
`collected-samples/<workspace>/<yyyymm>/<sha256>.png`，这样去重是全局的，同一张图不会存两份。

### 建版本的样本范围

| scope | 含义 |
|---|---|
| `OWN`（默认） | 本数据集导入的样本 + 识别页采集的样本；**不包含导入到其他数据集的图片** |
| `POOL` | 整个采集池（旧行为） |
| `sources` | 显式指定来源版本（优先级最高，用于合并） |

页面：建版本面板「样本范围」下拉，默认「仅本数据集（推荐）」。

### 实测（2026-11-18）

| 数据集 | OWN | POOL |
|---|---|---|
| SVHN-单字-演示（已导入 560 条） | 636（560 导入 + 76 识别采集） | 676 |
| 自采样本-241d67（没有导入） | 76（只有识别采集） | 676 |

这样“把 SVHN 导进数据集 9”不会再污染其他数据集的版本。

### 仍然存在的边界

- 识别页采集的样本没有归属数据集（`source_dataset_id` 为空），因此会出现在**所有**数据集的 OWN 版本里；
  只想看导入样本时用 `kind=IMPORTED` 过滤；
- 采集池没有单独的管理页（列/删/改标签），清理只能靠删数据集或直接操作数据库。
## 10. 数据集拥有样本（严格归属，2026-11-18 补）

现在样本的归属是**唯一**的：每条样本只属于一个数据集（source_dataset_id）。

- 导入到数据集 X → 归 X；
- 识别页采集的样本**没有归属**，需要点数据集面板里的「把识别采集的样本归入本数据集」才归入；
- 建版本 scope=OWN（默认）**只取本数据集的样本**，其他数据集的一条都不会混进来；
- scope=POOL 仍可显式选择“全部采集池”（兼容与合并场景）。

物理上图片仍存一份（按 sha256 去重），只是逻辑归属唯一。同一张图不能同时属于两个数据集；
需要跨集合并时用建版本的「样本来源」（复制样本行到新版本，不改归属）。

实测：

| 场景 | 结果 |
|---|---|
| 数据集 9（导入 560 条）建 OWN 版本 | 560 |
| 数据集 3（没有导入）建 OWN 版本 | 400（没有样本，提示先归入或导入） |
| 数据集 3 归入识别采集后再建 | 76 |

### 10.1 POOL 已移除（2026-11-18）

建版本不再提供「全部采集池」选项，scope 参数也从接口去掉：

- 版本 = 本数据集导入/归入的样本（唯一规则）；
- 需要跨集样本时用「样本来源」显式挑选；
- 识别页采集的样本先点「把识别采集的样本归入本数据集」。
